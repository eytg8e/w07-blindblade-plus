# PLAN_0008 — 쌍둥이 보스

## 목표

인간과 짐승의 협력 공격 및 생존자별 단독 공격을 기존 보스와 독립적으로 제공한다.

## 구현 단위

1. 전용 패턴 제어·인간 사격·짐승 이동 공격·반사 투사체를 하나의 통합 Task로 구현한다.
2. 별도 TwinBossTest 씬에 쌍둥이·플레이어·기존 NavMesh와 테스트 표시를 연결한다.

## 완료 조건

- 둘 다 생존할 때 탑승 패턴과 개별 패턴을 선택하고 한쪽 사망 후 생존자의 개별 패턴만 사용한다.
- 실제 피격 시 공격을 취소하고 피격된 생존 보스만 빠르게 걸어 회피한 뒤 다음 패턴을 선택한다.
- 협력 중 반사탄의 인간 적중은 파훼, 제한 시간 종료는 점프 공격으로 이어진다.
- 기존 보스·투사체·플레이어 코드와 씬 연결을 변경하지 않는다.
