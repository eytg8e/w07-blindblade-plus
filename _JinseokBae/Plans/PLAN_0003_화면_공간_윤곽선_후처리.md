# PLAN_0003 — 화면 공간 윤곽선 후처리

## 목표

환경의 깊이·노멀 차이를 화면 공간에서 검출하여 검은 배경 위에 밝은 윤곽선을 표시한다. 삼각형 분할선 대신 실루엣과 구조의 모서리를 표현하고, 기존 플레이어·감각 효과·UI 동작을 유지한다.

- 확인된 환경: Unity 6000.0.55f1, URP 17.0.4, 기본 파이프라인 PC_RPAsset, PC_Renderer의 기존 SSAO.
- 기본 방향: 후처리에서 환경 면 색상을 검게 합성하고 윤곽선을 표시한다. 전체 환경 재질을 Unlit으로 교체하지 않는다.
- 사용자 선택: B 학습형으로 전체 윤곽선을 먼저 구현한 뒤 위치·반경 기반 인지 마스크를 추가했다. Play에서는 관측자 주변을 상시 표시하고 소리 위치 주변을 일시 표시하며 조명·그림자·벽 차폐·파동 확산은 제외한다. 기존 SensoryLight와 플레이어 파동 스킬은 수정하지 않는다.
- 기존 DefaultVolumeProfile에 OutlineVolumeComponent 이름의 항목이 있으므로 실제 스크립트·활성 상태·소유자를 먼저 확인한다. 중복 구현 또는 작업 충돌이면 해당 수정 전에 승인을 받는다.
- 진행 상태: TASK_0019·0020·0022 완료. FootstepTest에서 정지 화면과 인지 마스크·소리 만료·발자국·웨이브 표시를 확인했다. TASK_0021의 대표 환경·성능·다른 해상도 검증은 미완료다.

## 구현 단위

1. [TASK_0019](../Tasks/TASK_0019_윤곽선_입력_및_합성_구현.md): 기존 윤곽선 흔적 확인, 깊이·노멀 검출 및 검은 면 합성 구현.
2. [TASK_0020](../Tasks/TASK_0020_윤곽선_렌더러_연결_및_설정.md): 실제 게임 카메라 렌더러 연결과 인스펙터 설정 제공.
3. [TASK_0021](../Tasks/TASK_0021_윤곽선_화면_및_조명_검증.md): 대표 화면·기존 효과 검증, 항상 표시 방식의 범위 및 기능명세 기록.
4. [TASK_0022](../Tasks/TASK_0022_위치_반경_기반_인지_마스크.md): 관측자 주변 상시 인지·소리 위치 주변 일시 인지와 세션 연결.

## 완료 조건

- 가려진 구조의 선은 표시하지 않고, 실루엣과 노멀 경계가 검은 면 위에서 읽힌다.
- 선 색상·굵기·깊이 및 노멀 민감도를 인스펙터에서 조절할 수 있다.
- 기존 SSAO·카메라·UI·발자국·웨이브·순간 빛의 동작을 확인하며, 누락되거나 변경되는 표현은 명시한다.
- Play 중에는 인지 반경으로 윤곽선을 제한하고 소리 영역은 수명에 따라 사라진다. 조명 밝기·표면 방향·그림자는 인지 판정에 사용하지 않는다. 편집 모드에서는 전체 선을 미리 본다.
- 투명 물체, 작은 볼트, 평면 경계의 검출 한계와 해상도별 선 품질을 기록한다. 선 메시·텍스처 보완은 이번 범위에 포함하지 않는다.
- 파동 스킬 구현, 매니저 리팩터링, 모바일 렌더러 확장은 포함하지 않는다.
