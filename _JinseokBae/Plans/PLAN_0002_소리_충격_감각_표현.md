# PLAN_0002 — 소리·충격 감각 표현

## 목표

걸음·충돌·소리 발생원이 사건 정보를 전달하면 게임 세션의 공통 Emitter가 관측자와의 거리 및 사건 종류에 따라 발자국·웨이브·순간 빛을 선택적으로 생성한다. 각 효과는 독립적인 재생과 수명을 유지한다.

- 책임 배치: Game은 게임 세션의 공통 Emitter 접근점을 제공하고, Managers는 기존 리소스·풀·사운드 서비스를 제공한다. 캐릭터 한 개의 FootstepEmitter를 Game에 보유시키는 이전 구조와 다르게, 이번 Emitter는 여러 발생원의 표현 요청을 처리한다.
- 접근 흐름: 발생원 → Game이 제공하는 공통 Emitter.Emit(사건 정보) → 거리·종류 정책 → Managers.Resource/Pool로 효과 생성 → 개별 효과의 수명 종료 및 반환.
- 공통 Emitter에 별도 싱글턴을 추가하지 않고 기존 Game 접근점을 사용한다. Game/Managers의 기존 싱글턴 기반 클래스와 공용 서비스를 재작성하지 않는다.
- 책임 배치 확정: 사용자가 Game의 공통 Emitter 보유와 Managers 공용 서비스 재사용을 선택했다. Managers에는 세션 Emitter나 플레이어 참조를 추가하지 않는다.

## 완료 조건

- 여러 오브젝트가 위치·종류·강도·표면 방향을 전달하고, 걸음에는 좌우 발 및 정렬 방향을 추가로 전달한다.
- 관측자 거리의 최대 표시 범위 밖에서는 발자국·웨이브·빛을 모두 생성하지 않는다. 경계에서는 종류별 공통 감쇠값을 각 효과에 전달한다.
- 걸음은 설정에 따라 발자국·웨이브·빛을, 일반 충돌·소리는 웨이브·빛을 표현한다. 사건이 발자국 종류가 아니면 발자국을 생성하지 않는다.
- 각 효과가 별도 프리팹·수명으로 동작하고 한 효과의 종료가 다른 효과를 종료하지 않는다.
- 캐릭터별 FootstepEmitter는 걸음 감지와 사건 전달만 담당한다. 관측자 거리 판단 및 프리팹 생성 책임은 공통 Emitter에 있다.
- 공통 Emitter와 관측자는 세션 시작 시 연결되고 교체·종료 시 갱신·해제된다. 없는 설정을 숨기기 위해 기본 Emitter나 플레이어를 자동 생성하지 않는다.
- 실제 소리 재생과 시각 효과 제한을 분리한다. 화면에 효과를 생성하지 않는다는 이유로 기존 소리 재생을 취소하지 않는다.
- 게임잼 1차 범위는 사건 발생 주변의 짧은 로컬 조명이다. 웨이브 도달 지점에 맞춘 순차 공간 공개, 벽 차폐, 셰이더 기반 공간 공개 및 다중 관측자는 후속 논의 대상으로 둔다.
- TASK_0009~0012의 구현과 코드 컴파일 및 TASK_0013 씬 연결은 완료했다. 실제 플레이 검증은 미확인이며 TASK_0013의 해당 항목은 미완료로 유지한다.
