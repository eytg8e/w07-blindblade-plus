# TASK_0084 — 플레이어 스태미나

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 공격·방어 자원과 화면 게이지를 추가한다.

- 공격 시작·방어 성공에 스태미나를 소모하고 0이면 새 공격·가드를 거부한다.
- 회복과 소모 수치는 인스펙터 설정으로 제공한다.

- [x] PlayerStamina를 공격·방어 성공 사건에 연결한다.

- [x] 하단 스태미나 게이지를 Player 프리팹에 연결한다.
- [x] 컴파일 오류·경고 0 및 프리팹·열린 씬 연결을 확인한다.

## 완료 조건

- 공격 ID당 한 번 소모하고 가드·패링 성공마다 소모한다.

- 회복 대기 후 공격·가드 외 상태에서 자동 회복한다.
