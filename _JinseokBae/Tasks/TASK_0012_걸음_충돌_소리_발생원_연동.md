# TASK_0012 — 걸음 충돌 소리 발생원 연동

## 목표

[PLAN_0002](../Plans/PLAN_0002_소리_충격_감각_표현.md)의 구현 단위 4을 수행한다. 각 오브젝트의 기존 발생 감지를 공통 사건 전달로 연결한다.

## 외부 상호작용 변화

- 캐릭터·충돌 오브젝트·소리 발생원이 위치와 사건 종류를 전달하고 직접 시각 프리팹 생성은 제거한다.

## 구현 항목

- [x] 기존 FootstepEmitter의 이동 간격·좌우·지면 검사·순간이동 처리와 캐릭터별 책임은 유지한다.
- [x] 걸음 감지 시 사건 정보를 공통 Emitter로 전달하고 기존 발자국 프리팹 생성·관측 거리 설정을 이관한다. 기존 OnFootstepEmitted 구독자를 확인해 중복 생성 없이 계약을 갱신한다.
- [x] 충돌 발생원은 접촉 위치·법선과 충격량을 전달한다. 물리량을 정규화 강도로 변환하는 기준과 최소 강도·재발생 간격은 인스펙터 설정으로 제공한다.
- [x] 일반 소리는 이미 확인된 소리 재생 지점에서 시각 사건을 알린다. Managers.Sound의 모든 재생을 임의로 가로채거나 AudioSource를 매 프레임 탐색하지 않는다.
- [x] 같은 소리·충돌이 양쪽 콜라이더나 기존 구독자로부터 중복 전달되지 않도록 발생원 단위의 전달 책임과 재발생 정책을 정한다.
- [x] 기존 SoundManager는 위치 없는 재생 API를 제공하므로 기존 API를 공간 음향 기능으로 간주하지 않는다. 실제 공간 음향 추가가 필요하면 별도 범위를 제안한다.

## 완료 조건

- 걸음에는 발자국 정보가 포함되고 일반 충돌·소리에는 발자국이 생성되지 않는다.
- 한 발생 사건의 시각 효과가 중복 생성되지 않으며 기존 소리 재생 동작을 유지한다.

## 검증

- Unity 참조 기반 C# 컴파일 및 연결 파일의 내부 참조 확인 완료. 실제 PlayMode 동작은 TASK_0013에서 미확인으로 관리한다.
