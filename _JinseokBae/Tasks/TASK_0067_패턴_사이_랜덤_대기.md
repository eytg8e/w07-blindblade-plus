# TASK_0067 — 패턴 사이 랜덤 대기

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 각 패턴 사이에 3~5초의 랜덤 대기를 둔다.

## 변경

- 패턴 시작 전 이동을 멈추고 랜덤 시간 동안 대기한다.
- 피격 후 복귀도 대기하며 연속 돌진 내부 간격은 유지한다.

## 구현 항목

- [x] 최소·최대 대기 시간을 인스펙터에 노출한다.
- [x] 대기 중 피격 시 예약된 다음 패턴을 유지한다.
- [x] 컴파일과 랜덤 대기 설정·연결을 확인한다.

## 완료 조건

- 각 패턴 시작 전에 기본 3~5초를 기다린다.
- 기존 피격 퇴장과 다음 패턴 순환을 유지한다.
