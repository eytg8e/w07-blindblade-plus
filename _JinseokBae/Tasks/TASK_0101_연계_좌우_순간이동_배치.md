# TASK_0101 — 연계 좌우 순간이동 배치

## 목표

- 기존 전방 거리·간격 필드와 공격 순서·연계 속도를 유지한다.

## 구현 항목

- [x] Unity 컴파일 완료·실패 없음·오류 없음 상태를 확인하고 기능명세·WorkLog를 갱신한다.

## 완료 조건

- 기본 전방 3m 중심에서 짐승 좌측 1m·인간 우측 1m로 배치한다.
