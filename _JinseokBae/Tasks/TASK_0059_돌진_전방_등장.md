# TASK_0059 — 돌진 전방 등장

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 돌진 등장 위치를 플레이어 시점 기준 전방 180도로 제한한다.

## 변경

- 단일 돌진과 연속 돌진의 각 준비 전에 전방 반원에서 등장한다.

## 구현 항목

- [x] 등장 각도를 인스펙터 설정으로 노출하고 시점 기준 후보를 선택한다.
- [x] NavMesh 보정 후 뒤쪽 후보를 거부한다.
- [x] 단일 돌진과 연속 돌진에 같은 위치 선택을 적용한다.
- [x] 컴파일 및 전방 후보 연결을 확인한다.

## 완료 조건

- 등장 순간 플레이어 시점 기준 뒤쪽에서 돌진을 준비하지 않는다.
- 유효한 전방 위치가 없으면 해당 돌진을 생략한다.
