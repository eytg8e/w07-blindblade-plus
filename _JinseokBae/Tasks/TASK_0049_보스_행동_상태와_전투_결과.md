# TASK_0049 — 보스 행동 상태와 전투 결과

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 구현 단위 2를 달성한다. TASK_0048 완료 후 진행한다.

## 변경

- 보스 전용 행동 진행과 생명주기를 관리하고 기존 피해·패링 결과를 연결한다.
- 일반 적의 추적·공격 선택과 보스 제어가 중복되지 않게 한다.
- 구현 전 패턴 선택·복귀 규칙과 돌진의 적중·패링 처리 규칙을 사용자와 확정한다.

## 구현 항목

- [ ] 배회·단일 돌진·연속 돌진·정면승부·스턴·사망 상태 및 전환 계약을 마련한다.
- [ ] 기존 `DamageContext`, `EnemyHealth`, 카타나 방어 계약을 확인하고 필요한 변경 범위를 정한다.
- [ ] 보스의 타격을 기존 방어 판정이 인식하게 연결한다. 다른 스크립트의 연관 변경이 필요하면 대상과 이유를 먼저 제안한다.
- [ ] 공격자·개별 타격을 식별하여 중복 패링 집계와 일반 가드의 패링 집계를 막는다.
- [ ] 사망·대상 상실·비활성화 시 이동·공격·코루틴·이벤트 구독을 정리한다.
- [ ] 보스전 기능명세를 생성하여 `docs/FEATURE_SPEC.md`에 등록하고 구현된 범위만 기록한다.
- [ ] 컴파일과 생명주기 연결을 확인하고 WorkLog 기록 후 이 Task 변경만 커밋한다.

## 완료 조건

- 하나의 보스 행동만 실행되고 일반 적 제어가 개입하지 않는다.
- 공격 결과를 피해·가드·패링으로 구분하고 다른 적의 결과를 사용하지 않는다.
- 대상이 없어지거나 보스가 종료되어도 예약 공격이 실행되지 않는다.
- 미구현 패턴은 완료로 표시하지 않으며 상태 기반이 검증·커밋된 후 다음 Task를 시작한다.
