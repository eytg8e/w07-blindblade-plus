# TASK_0063 — 보스 발자국 표현과 피격 중단

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 보스 외형을 숨기고 발자국으로 위치를 표현하며 피격 시 행동을 중단한다.

## 변경

- 모든 상태에서 외형을 숨기고 배회·돌진·정면승부 이동에 발자국을 생성한다.
- 피격 시 이동·공격을 취소하고 기본 0.5초 정지 후 배회로 복귀한다.

## 구현 항목

- [x] 외형을 상시 숨기고 이동 발자국 조건을 확대한다.
- [x] 피격 시 코루틴·근접 공격·이동을 취소하고 정면승부 NavMesh를 복구한다.
- [x] 컴파일 및 피격 취소·외형 숨김을 확인한다.

## 완료 조건

- 보스 외형이 나타나지 않고 실제 피격 즉시 기존 행동이 멈춘다.
- 피격 정지 시간은 인스펙터에서 조절하며 사망·비활성화 시 재개하지 않는다.
