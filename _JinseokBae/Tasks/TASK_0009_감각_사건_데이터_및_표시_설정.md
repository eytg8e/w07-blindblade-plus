# TASK_0009 — 감각 사건 데이터 및 표시 설정

## 목표

[PLAN_0002](../Plans/PLAN_0002_소리_충격_감각_표현.md)의 구현 단위 1을 수행한다. 공통 Emitter에 전달할 사건 정보와 인스펙터 기반 표시 정책을 정의한다.

## 외부 상호작용 변화

- 발생원은 효과 프리팹 대신 사건 데이터를 전달하고 종류별 설정이 표현 조합을 결정한다.

## 구현 항목

- [x] 걸음·충돌·일반 소리의 사건 종류와 구조체 데이터 정의: 월드 위치, 표면 법선, 방향, 강도, 발생원, 걸음 좌우 정보.
- [x] 강도는 정규화된 0~1 신호로 정하고 충돌 물리량은 발생원에서 변환한다. 지면 정보가 없는 소리 사건의 기본 방향과 발자국 없는 처리도 정의한다.
- [x] 종류별 완전 표시 거리·최대 표시 거리(미터), 감쇠 곡선, 발자국·웨이브·빛 프리팹과 재생 수치를 직렬화 설정 또는 ScriptableObject로 정의한다.
- [x] 반복 전달 경로의 할당과 LINQ를 피하고 기존 이름·직렬화 GUID는 필요한 변경 외에 보존한다.

## 완료 조건

- 각 사건이 효과 선택 및 발자국 정렬에 필요한 정보를 갖춘다.
- 거리·강도의 단위와 범위가 명확하며 발자국 종류 외에는 좌우 정보가 요구되지 않는다.
