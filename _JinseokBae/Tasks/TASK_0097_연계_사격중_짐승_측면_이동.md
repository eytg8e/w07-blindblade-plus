# TASK_0097 — 연계 사격 중 짐승 측면 이동

## 목표

[PLAN_0008](../Plans/PLAN_0008_쌍둥이_보스.md)의 점프·사격 연계에서 짐승이 착지 후 대기만 하는 동작을 개선한다.

## 변경

- 짐승은 착지 후 짧게 후퇴하고 인간 사격 동안 플레이어 측면의 고정 목표로 이동한다.
- 후퇴·측면 이동은 공격 판정 없이 기존 NavMesh 이동을 사용한다.
- 인간 사격 종료·피격·사망 시 이동을 정리한다.

## 구현 항목

- [x] 착지 후 후퇴와 사격 중 측면 이동을 추가한다.
- [x] 후퇴 거리·속도와 측면 반경·속도를 인스펙터와 프리팹에 설정한다.
- [x] 컴파일·설정·사격 중 실제 이동과 피격 취소를 확인하고 기능명세·WorkLog를 갱신한다.

## 완료 조건

- 짐승은 인간 사격 중 측면으로 이동하며 해당 이동 자체는 피해를 주지 않는다.
- 유효한 이동 지점이 없으면 후속 사격을 유지하고 기존 취소·회피 수명을 유지한다.
