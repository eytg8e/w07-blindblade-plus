# TASK_0020 — 윤곽선 렌더러 연결 및 설정

## 목표

[PLAN_0003](../Plans/PLAN_0003_화면_공간_윤곽선_후처리.md)의 구현 단위 2를 달성한다. TASK_0019 완료 후 진행한다.

## 변경

- 외부 상호작용 변화: 실제 게임 카메라에 효과를 적용하고 개발자가 인스펙터에서 표현을 조절한다.
- 기존 렌더러 기능과 직렬화 참조를 보존하며 적용할 카메라·렌더러 범위를 확인한다.

## 구현 항목

- [x] 게임 카메라가 사용하는 렌더러와 카메라 스택, 후처리 순서 및 UI 렌더 방식을 확인한다.
- [x] 해당 렌더러에 효과를 연결하고 기존 SSAO 등 렌더러 기능을 보존한다.
- [x] 선 색상, 선 굵기(렌더링 픽셀 기준), 깊이·노멀 검출 민감도, 활성 설정을 제공한다.
- [x] 설정의 단위와 유효 범위를 표시하고 셰이더·머티리얼 연결을 확인한다.
- [x] 씬·프리팹 변경이 필요하면 대상과 이유를 확인하고 저장되지 않은 편집과의 충돌을 피한다.

- 결과: PC_Renderer > Screen Space Outline에 설정을 모았다. 활성은 Renderer Feature 기존 체크박스이며 별도 설정 컴포넌트·Volume은 추가하지 않았다.
- 연결: PC 품질 설정의 PC_RPAsset → PC_Renderer, SampleScene·FootstepTest·PlayerDebugSandbox 직렬화 카메라는 기본 렌더러(-1)와 빈 스택을 사용한다. SampleScene·PlayerDebugSandbox의 Canvas는 Screen Space Overlay다.
- 검증: FootstepTest의 1280×720 카메라 캡처에서 효과 적용, 폭 1→3 변경, 비활성 시 기존 화면 복귀를 확인했다. 활성 true·폭 1로 복원했으며 에디터 오류 0건이다.
- 수동 연결: 없음. 기존 렌더러·셰이더 GUID를 연결하고 SSAO와 씬·프리팹은 보존했다. 다른 씬의 실제 화면 및 UI 검증은 TASK_0021에 남긴다.

## 완료 조건

- 게임 카메라에 효과가 적용되고 비활성화하면 기존 렌더링으로 돌아간다.
- 인스펙터 조절 결과가 화면에 반영된다.
- 기존 GUID·참조와 다른 렌더러 기능을 보존하고, 추가 수동 연결이 필요하면 정확한 대상을 기록한다.
