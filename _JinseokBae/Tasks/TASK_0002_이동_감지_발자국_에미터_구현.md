# TASK_0002 — 이동 감지 발자국 에미터 구현

## 목표

[PLAN_0001](../Plans/PLAN_0001_발자국_시스템.md)의 구현 단위 2를 달성한다. 캐릭터의 이동 거리를 누적 감지하여 일정 거리마다 좌/우 발자국을 지면 레이캐스트 위치에 스폰하고 관측자 거리에 따른 가시성을 제어한다.

## 변경

- `FootstepEmitter.cs`: 이동 거리 누적, 지면 Raycast 및 법선 정렬 스폰, 거리 기반 가시성 계산, 파동 이벤트(`OnFootstepEmitted`) 발행

## 구현 항목

- [x] 이동 거리 누적(`_accumulatedDistance`) 및 발자국 스폰 트리거
- [x] 좌/우 교대 오프셋 및 지면 정렬 Raycast 처리
- [x] 관측자 거리 기반 발자국 가시성 알파 및 최대 거리 필터링
- [x] `OnFootstepEmitted` 정적 이벤트 발행

## 완료 조건

- 캐릭터 이동 시 좌/우 발자국이 지면에 정상 배치된다.
- 관측자와 거리가 멀어질수록 발자국이 투명해지며, 최대 거리 밖에서는 생성이 건너뛰어진다.
