# TASK_0068 — 피격 후 대기 중 재타격 방지

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 피격 후 복귀 대기 중 연타로 행동이 계속 취소되는 문제를 막는다.

## 변경

- 다음 패턴이 시작될 때까지 전투 공간 밖의 무적·충돌체 비활성 상태를 유지한다.

## 구현 항목

- [x] 피격 정지 직후의 조기 복귀를 제거한다.
- [x] 패턴 대기 종료 시 위치·무적·충돌체를 복구한다.
- [x] 컴파일 및 대기 종료 시 복귀하는 코드 연결을 확인한다.
- [ ] 실제 연타 입력으로 대기 중 피해 차단을 확인한다.

## 완료 조건

- 피격 후 0.5초가 지나도 다음 패턴 대기 중에는 추가 피해를 받지 않는다.
- 대기 종료 시 정상 복귀하고 다음 패턴을 진행한다.
