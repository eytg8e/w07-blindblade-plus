# TASK_0096 — 쌍둥이 협력 연계와 피격 회피

## 목표

[PLAN_0008](../Plans/PLAN_0008_쌍둥이_보스.md)의 최신 협력 전용 생존 규칙과 피격 회피를 적용한다.

## 변경

- 둘 다 생존하면 탑승 사격과 짐승 전방 접근·점프→인간 사격만 선택한다.
- 단독 사격·지그재그·점프는 한쪽만 생존할 때 선택한다.
- 실제 피격은 현재 패턴과 탄환을 취소하고 생존자들이 빠르게 걸어 회피한 뒤 다음 패턴으로 이어진다.
- 회피·회복 중에는 추가 피해를 받지만 회피를 재시작하지 않는다.

## 구현 항목

- [x] 생존 조건별 패턴 선택과 점프·사격 연계를 구현한다.
- [x] 피격·반사탄 공통 중단과 NavMesh 회피·회복 수명을 구현한다.
- [x] 프리팹 수치와 기능명세·WorkLog를 갱신한다.
- [x] Unity 컴파일 및 설정 연결을 확인한다.

## 완료 조건

- 협력과 단독 패턴이 생존 조건에 맞게 선택된다.
- 피격 시 남은 연계가 실행되지 않고 공격 없는 회피 후 다음 패턴을 시작한다.
- 사망·비활성화 시 이동·공격과 이벤트 구독을 정리한다.
