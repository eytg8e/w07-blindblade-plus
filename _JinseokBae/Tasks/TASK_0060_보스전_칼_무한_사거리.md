# TASK_0060 — 보스전 칼 무한 사거리

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 플레이어 칼을 거리 제한 없이 사용한다.

## 변경

- 보스전 칼 공격은 시점 방향으로 거리 제한 없이 적중을 검사한다.
- 기존 벽 차폐·공격당 피해 1회·칼 모델을 유지한다.

## 구현 항목

- [x] EnemyCombatService에 선택적인 무한 사거리 판정을 추가한다.
- [x] BossBattle 플레이어에 무한 사거리 설정을 연결한다.
- [x] 컴파일·원거리 적중·중복 피해·벽 차폐를 확인한다.

## 완료 조건

- 보스전 일반·발도 베기가 사거리 밖의 전방 보스에게 피해를 준다.
- 다른 씬의 기존 칼날 판정은 유지한다.
