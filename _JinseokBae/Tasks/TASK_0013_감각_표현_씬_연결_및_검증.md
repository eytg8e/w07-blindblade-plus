# TASK_0013 — 감각 표현 씬 연결 및 검증

## 목표

[PLAN_0002](../Plans/PLAN_0002_소리_충격_감각_표현.md)의 구현 단위 5을 수행한다. 게임 세션과 발생원 및 독립 효과의 실제 씬 연결을 완료하고 동작을 확인한다.

## 외부 상호작용 변화

- 테스트 씬에서 걸음·충돌·일반 소리 사건을 같은 거리 기준으로 표현한다.

## 구현 항목

- [x] 기존 테스트 씬에 세션 공통 Emitter, 관측자, 사건별 표시 설정 및 발자국·웨이브·빛 프리팹을 연결한다.
- [x] FootstepTestDriver의 임시 직접 웨이브 생성 경로를 공통 요청 경로로 갱신해 이중 생성하지 않는다.
- [ ] 가까움·감쇠 구간·최대 거리 경계·범위 밖에서 각 사건 종류의 효과 조합을 확인한다.
- [ ] 생성 후 관측자 이동, 관측자 교체·파괴, 세션 종료와 재시작, 다수 발생원, 효과별 독립 수명 및 풀 재사용을 확인한다.
- [ ] 발자국은 지면 정렬과 좌우 교대를 확인하고 충돌·일반 소리는 발자국 미생성을 확인한다. 실제 소리 재생은 시각 거리 제한과 독립적이어야 한다.
- [x] 새 테스트 코드·임시 검증 시스템을 임의 작성하지 않고 기존 실행 수단을 사용한다. 플레이 검증을 못 한 항목은 미확인으로 남긴다.
- [x] 관련 기능명세에 최종 API·책임·씬 연결과 검증 결과를 반영하고 실제 완료한 항목만 체크한다.

## 완료 조건

- 최대 거리 밖에서는 발자국·웨이브·빛이 모두 표시되지 않는다.
- 추가 연결이 필요한 컴포넌트·프리팹 및 미검증 항목이 문서에 명시된다.

## 검증 결과

- C# 컴파일 성공, 씬·프리팹·설정의 내부 fileID 및 필수 연결 확인 완료.
- 실제 플레이 검증 미확인: Unity CLI 연결은 다른 프로젝트만 제공하고 해당 Unity 에디터 컴퓨터 제어 연결은 시간 초과로 실패했다.
- 거리 경계, 관측자 이동·교체·파괴, 세션 종료·재시작, 충돌 중복 방지, 좌우 배치 및 독립 수명·풀 재사용의 실행 확인은 남겨 둔다.
- 추가 인스펙터 연결: FootstepTest 씬에는 없음. 다른 게임 씬은 Game의 Emitter, Emitter의 관측자와 세 설정, 캐릭터 지면 레이어를 연결해야 한다.
