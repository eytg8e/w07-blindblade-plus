# TASK_0021 — 윤곽선 화면 및 조명 검증

## 목표

[PLAN_0003](../Plans/PLAN_0003_화면_공간_윤곽선_후처리.md)의 구현 단위 3을 달성한다. TASK_0020 완료 후 진행한다.

## 변경

- 외부 상호작용 변화: 대표 환경에서 윤곽선 가독성과 기존 효과의 가시성을 확인하고 조명 공개 요구의 적용 방식을 확정한다.
- 사용자 선택: 전체 윤곽선 구현 후 TASK_0022에서 위치·반경 기반 인지를 추가했다. 실제 조명 밝기·그림자 기반 제한은 사용하지 않는다.
- 별도 마스크나 다른 시스템의 코드 변경이 필요하면 대상·인터페이스·이유를 먼저 제안하고 승인 후 진행한다. 플레이어 파동 스킬은 구현하지 않는다.

## 구현 항목

- [ ] 기존 검증 수단으로 벽·난간·파이프의 실루엣과 내부 모서리, 가려진 면을 확인한다.
- [ ] 카메라 이동 및 해상도 변화에서 선 굵기·깜빡임·원거리 잡음을 확인한다.
- [ ] UI, 발자국, 웨이브의 기존 표시와 수명을 확인한다. SensoryLight는 후속 TASK_0023에서 사용자 요청으로 제거했다.
- [x] 조명과 무관한 기본 윤곽선을 확인하고 후속 TASK_0022에서 인지 반경·시간 기반 표시로 확장한다.
- [ ] 투명 물체·평면 경계·작은 디테일 및 성능의 확인 결과와 미확인 범위를 기록한다.
- [x] 구현된 실제 파일·클래스·연결·설정으로 기능명세를 작성하고 docs/FEATURE_SPEC.md에 등록한다.
- [x] 완료된 Task 결과만 당일 WorkLog에 기록한다.

- 부분 검증: FootstepTest의 정지 카메라 1280×720 캡처에서 검은 면·배경 위에 불투명 물체의 실루엣과 내부 경계가 나타남을 확인했다. 폭 조정과 비활성 복귀도 확인했으며 컴파일·렌더 오류 0건이다.
- 후속 검증: TASK_0022에서 FootstepTest Play의 UI·발자국·웨이브 표시와 소리 인지 영역 만료를 확인했다. 이 Task는 대표 환경·가려진 면·이동 시 선 품질·다른 해상도·성능·전체 효과 수명 검증이 남아 미완료다.

## 완료 조건

- 대표 화면에서 검은 면과 밝은 선으로 구조를 읽을 수 있으며 기존 효과·UI가 유지된다.
- 조명과 무관한 인지 반경 표시와 조명 마스크 제외 범위가 명세에 기록된다. 실행하지 못한 검증 항목은 미완료로 남긴다.
- 테스트 코드나 임시 검증 스크립트를 새로 만들지 않고 실제 실행 여부와 한계를 명시한다.
