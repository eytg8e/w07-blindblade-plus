# TASK_0021 — 윤곽선 화면 및 조명 검증

## 목표

[PLAN_0003](../Plans/PLAN_0003_화면_공간_윤곽선_후처리.md)의 구현 단위 3을 달성한다. TASK_0020 완료 후 진행한다.

## 변경

- 외부 상호작용 변화: 대표 환경에서 윤곽선 가독성과 기존 효과의 가시성을 확인하고 조명 공개 요구의 적용 방식을 확정한다.
- 조명 후보는 기존 조명 결과의 밝기로 선을 제한하는 방식과 별도 공간 마스크 방식이다. 기존 렌더 결과의 밝기는 재질·발광에도 영향을 받으므로 조명 전용 정보로 단정하지 않는다.
- 별도 마스크나 다른 시스템의 코드 변경이 필요하면 대상·인터페이스·이유를 먼저 제안하고 승인 후 진행한다. 플레이어 파동 스킬은 구현하지 않는다.

## 구현 항목

- [ ] 기존 검증 수단으로 벽·난간·파이프의 실루엣과 내부 모서리, 가려진 면을 확인한다.
- [ ] 카메라 이동 및 해상도 변화에서 선 굵기·깜빡임·원거리 잡음을 확인한다.
- [ ] UI, 발자국, 웨이브, SensoryLight의 기존 표시와 수명을 확인한다.
- [ ] 조명에 따른 선의 밝기 변화 방식을 사용자와 확정하고, 승인된 범위만 구현·검증한다.
- [ ] 투명 물체·평면 경계·작은 디테일 및 성능의 확인 결과와 미확인 범위를 기록한다.
- [ ] 구현된 실제 파일·클래스·연결·설정으로 기능명세를 작성하고 docs/FEATURE_SPEC.md에 등록한다.
- [ ] 완료된 Task 결과만 당일 WorkLog에 기록한다.

## 완료 조건

- 대표 화면에서 검은 면과 밝은 선으로 구조를 읽을 수 있으며 기존 효과·UI가 유지된다.
- 조명 공개의 확정된 동작과 구현 범위가 명세에 기록된다. 방식만 결정했거나 실행하지 못한 항목은 미완료로 남긴다.
- 테스트 코드나 임시 검증 스크립트를 새로 만들지 않고 실제 실행 여부와 한계를 명시한다.
