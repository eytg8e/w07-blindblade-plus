# TASK_0089 — 보스 배회와 미사용 패턴 제거

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 보스 컨트롤러에서 배회와 호출되지 않는 패턴 코드를 제거한다.

## 변경

- 보스는 원거리→단일 돌진을 반복하며 피격 후 다음 공격 패턴을 재개한다.
- 외부에서 참조하는 상태 enum과 이벤트, 기존 재배치·피격 처리는 유지한다.

## 구현 항목

- [x] 배회 코루틴·설정과 배회로의 전환을 제거한다.
- [x] 미사용 연속 돌진·정면승부·스턴 구현 및 전용 필드·이벤트 구독을 제거한다.
- [x] 관련 기능명세와 WorkLog를 갱신한다.
- [ ] Unity 컴파일 및 플레이에서 패턴 순환을 확인한다.

## 완료 조건

- 배회 없이 원거리→돌진이 반복되고 피격 후 원거리와 돌진 사이를 전환한다.
- 외부 상태 참조와 재배치·피격·전투 종료 계약을 유지한다.
