# TASK_0011 — 독립 효과 재생 및 순간 빛

## 목표

[PLAN_0002](../Plans/PLAN_0002_소리_충격_감각_표현.md)의 구현 단위 3을 수행한다. 공통 거리 감쇠값을 사용하는 발자국·웨이브·순간 빛의 독립 생명주기를 연결한다.

## 외부 상호작용 변화

- 공통 Emitter가 효과를 각각 생성하고 각 효과는 독립적으로 재생·종료·풀 반환한다.

## 구현 항목

- [x] FootstepObject에서 관측자 직접 참조와 독자 거리 정책을 공통 Emitter 정책으로 이관한다. 재생 데이터로 좌우 정보와 감쇠값을 전달한다.
- [x] FootstepWave의 독립 프리팹·코루틴 수명을 유지하고 공통 감쇠값을 초기 알파에 적용한다. 이름 변경만을 위한 리팩터링은 하지 않는다.
- [x] 짧게 켜졌다 사라지는 로컬 빛 효과와 프리팹을 구성한다. 강도·범위·수명·페이드 시간은 인스펙터에서 조절한다.
- [x] 기존 Poolable/Resource 반환 계약을 재사용하고 재생·비활성화·재사용 시 코루틴과 색상·조명 상태를 초기화한다.
- [x] 생성 후 플레이어가 멀어지는 경우에도 같은 공통 거리 정책으로 남아 있는 효과의 가시성을 갱신한다. 공통 Emitter의 활성 효과 목록과 효과의 가시성 적용 API로 처리하고 효과별 플레이어 탐색은 추가하지 않는다.
- [x] 빛·웨이브·발자국별 수명은 독립적으로 적용한다. 하나의 객체 아래에 모든 효과를 묶어 동시 종료시키지 않는다.

## 완료 조건

- 발자국이 종료되어도 독립 웨이브·빛은 각자 수명에 따라 동작한다.
- 생성 후 최대 거리 밖으로 멀어지면 남아 있는 효과도 보이지 않고 자기 수명 종료 시 반환된다.

## 검증

- Unity 참조 기반 C# 컴파일 및 연결 파일의 내부 참조 확인 완료. 실제 PlayMode 동작은 TASK_0013에서 미확인으로 관리한다.
