# TASK_0106 — 카메라 상하 회전 복원

## 목표

카메라 수평 고정을 해제하고 상하 시점을 허용한다.

## 외부 상호작용 변화

- 마우스 상하 입력을 카메라와 논리 조준 방향에 반영한다.
- 상하 허용 각도는 기본 ±89도이며 Inspector에서 조절한다.

## 구현 항목

- [x] PlayerMotor의 상하 입력·초기 회전·LateUpdate·ViewForward를 복원한다.
- [x] 컴파일 및 기능명세·WorkLog 갱신을 완료한다.

## 완료 조건

- 카메라 수평 고정이 사라지고 상하 입력이 유지된다.
