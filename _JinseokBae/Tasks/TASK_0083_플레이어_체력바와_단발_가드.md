# TASK_0083 — 플레이어 체력바와 단발 가드

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 플레이어 체력 표시와 공격 한 번 방어 후 가드 해제를 구현한다.

## 변경

- 화면 하단 체력바를 플레이어 체력 사건에 연결한다.
- 가드·패링 성공 후 가드를 종료하며 기존 성공 피드백은 유지한다.

## 구현 항목

- [x] Player 프리팹에 체력바를 연결한다.
- [x] 방어 성공 시 EndDefense를 호출하고 새 입력에만 가드를 시작한다.
- [x] 컴파일 오류·경고 0 및 PlayerHealthBar 프리팹·씬 연결을 확인한다.

## 완료 조건

- 실제 체력 비율이 하단에 표시되고 방어 성공 직후 유지 가드가 종료된다.
