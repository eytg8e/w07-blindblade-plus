# TASK_0025 — 현재 플레이어 참조 관리

## 목표

[PLAN_0005](../Plans/PLAN_0005_게임_씬_공통_구조_및_입력_관리.md)의 구현 단위 1에서 현재 플레이어 접근점과 등록 수명을 마련한다.

## 변경

- PlayerController가 Awake에서 Game에 등록되고 파괴 시 등록을 해제한다.
- StageDoor와 StageSwordNoise는 씬에 직렬화된 플레이어 대신 Game.Player를 사용한다.
- MainMapSession과 CorridorRoundController의 연결 전환은 TASK_0027·0029에서 구현했다.

## 구현 항목

- [x] Game.Player 읽기 전용 접근점과 동일 인스턴스 등록 해제 구현
- [x] 생존 플레이어 중복 등록 거부
- [x] 문 및 검 소음의 현재 플레이어 연결과 이벤트 구독 수명 반영
- [x] Unity 컴파일 및 실제 Play 씬 전환의 플레이어 등록 확인
- [ ] 전체 문 통과·검 소음 플레이 검증

## 완료 조건

- 플레이어 파괴 시 Game.Player가 이전 객체를 유지하지 않는다.
- 문과 검 소음이 현재 플레이어로 동작하며 씬별 플레이어 수동 연결을 요구하지 않는다.
- 컴파일과 실행 결과를 기록하며 미검증 항목은 완료로 표시하지 않는다.
