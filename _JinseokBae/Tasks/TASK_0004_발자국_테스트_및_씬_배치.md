# TASK_0004 — 발자국 테스트 및 씬 배치

## 목표

[PLAN_0001](../Plans/PLAN_0001_발자국_시스템.md)의 실제 연결 가능한 시각 리소스와 테스트 씬을 제공하고 관련 자동 테스트를 실행한다.

## 변경

- 전용 테스트 씬과 좌우 발자국 및 링 프리팹을 자동 연결한다.
- 테스트 씬에서 캐릭터를 자동 이동시키고 관측 거리를 조절한다.
- 사용자 요청에 따라 Unity Test Framework 테스트 스크립트를 추가한다.

## 구현 항목

- [x] 발자국 및 링 스프라이트, 머티리얼, 프리팹 생성
- [x] 독립 테스트 씬과 자동 이동 스크립트 배치
- [x] PlayMode 테스트 10개 작성 및 게임·생성·테스트 코드 컴파일 확인
- [x] 씬과 프리팹의 내부 fileID 및 외부 GUID 연결 확인
- [ ] 생성 간격, 좌우 배치, 지면, 순간이동, 거리 가시성 및 풀 반환 테스트 실행

## 완료 조건

- 테스트 씬의 모든 필수 참조가 연결되어 수동 연결 없이 재생된다.
- 자동 테스트 실행 결과와 확인하지 못한 시각 검증을 구분해 기록한다.
- 현재 상태: 구현 및 정적 연결 확인 완료, Unity 실행 검증 대기. 연결 도구의 승인 정책 및 배치 실행의 Package Manager IPC 소켓 권한 오류로 실행하지 못했다.
