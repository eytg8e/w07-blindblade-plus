# TASK_0008 — 캐릭터 발자국 책임 분리

## 목표

[PLAN_0001](../Plans/PLAN_0001_발자국_시스템.md)의 캐릭터별 발자국 책임과 게임 세션 책임을 분리한다.

## 변경

- Game의 단일 FootstepEmitter 참조를 제거한다.
- 시연 스크립트는 캐릭터의 Emitter를 인스펙터로 연결하여 직접 구독한다.
- 캐릭터별 인스턴스 이벤트와 기존 생성 로직은 유지한다.

## 구현 항목

- [x] Game 참조 제거 및 시연 구독 변경
- [x] 테스트 씬의 직접 Emitter 연결 반영
- [x] 코드 컴파일 및 기능명세 갱신

## 완료 조건

- 발자국 구독과 동작에 Game 싱글턴 접근이 없다.
- 사용자가 변경한 Game.Awake와 FootstepObject 및 삭제한 테스트·생성 코드는 보존한다.

- 검증: 게임 코드 컴파일 및 시연-캐릭터 Emitter 직렬화 참조 확인 완료, 실제 PlayMode 실행 미확인. 삭제된 기존 테스트는 복원하지 않았다.
