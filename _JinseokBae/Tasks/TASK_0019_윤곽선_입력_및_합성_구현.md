# TASK_0019 — 윤곽선 입력 및 합성 구현

## 목표

[PLAN_0003](../Plans/PLAN_0003_화면_공간_윤곽선_후처리.md)의 구현 단위 1을 달성한다.

## 변경

- 외부 상호작용 변화: 환경의 깊이·노멀 경계를 밝은 선으로, 면을 검은색으로 표시하는 후처리를 제공한다.
- 깊이는 실루엣·앞뒤 경계를, 노멀은 표면 방향의 경계를 검출하는 데 사용한다.
- 기존 재질·매니저·스킬 API는 수정하지 않는다.

## 구현 항목

- [x] 기존 OutlineVolumeComponent 항목의 스크립트·활성 상태·담당 영역을 확인하고 중복 여부를 판단한다.
- [x] 실제 프로젝트의 URP 실행 설정과 깊이·노멀 입력 제공 방식을 확인한다.
- [x] 프로젝트 설정에 맞는 렌더 패스와 셰이더로 경계 검출·검은 면 합성을 구현한다.
- [x] 효과 비활성화 시 기존 화면을 유지하고 생성한 렌더 리소스의 수명을 정리한다.
- [x] 요청 범위의 컴파일 오류를 확인하고, 미검증 항목을 기록한다.

- 결과: OutlineVolumeComponent는 Enabled=0, 참조 스크립트 GUID를 찾지 못했으며 동작하는 기존 윤곽선 코드는 발견되지 않았다. 소유자는 미확인이고 기존 항목은 보존했다.
- 결과: URP 17.0.4의 Render Graph 활성 설정을 확인하고 Depth·Normal 입력 요청 및 직접 카메라 색상 출력으로 구현했다. 머티리얼은 Create/Dispose에서 해제한다.
- 검증: 기존 Unity 컴파일 응답 파일 기반 C# 컴파일 및 대상 에디터 재컴파일 완료, 오류 0건. FootstepTest 카메라 렌더에서 셰이더 실행과 효과 비활성 시 기존 화면 복귀를 확인했다. 호환 모드 실행은 미확인이다.

## 완료 조건

- 깊이와 노멀 입력으로 선을 생성하며 메시 삼각형 분할선을 직접 그리지 않는다.
- 기존 윤곽선 기능과 중복되면 임의 교체하지 않고 승인 후 진행한다.
- 렌더러 연결과 실제 플레이 검증은 다음 Task에서 수행하며 이번 Task 완료로 대신하지 않는다.
