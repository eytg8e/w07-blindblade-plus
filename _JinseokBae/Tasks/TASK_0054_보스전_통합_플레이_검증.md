# TASK_0054 — 보스전 통합 플레이 검증

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 구현 단위 6 중 통합 검증을 마쳐 보스전 씬을 완성한다. TASK_0053 완료 후 진행한다.

## 변경

- 실제 씬의 사운드 중심 교전과 종료·재시작 흐름을 검증한다.
- 검증에서 확인된 요청 범위 내 결함만 수정하고 최종 기능명세를 정리한다.

## 구현 항목

- [x] 기존 Unity 검증 수단으로 컴파일과 실행 오류·누락 참조를 확인한다.
- [x] 시점 처리에 전달한 상하 입력과 반동에서 회전 제한 및 좌우 회전을 확인하고 실제 공격·가드를 확인한다.
- [x] 배회 비노출·피해 적용·제한 시간 돌진과 공간 재생 위치 연결을 확인한다.
- [x] 연속 돌진의 위치·매회 전조·총 3회 실행·벽 앞 정지를 확인한다.
- [x] 준비 중 이동·회전 추종과 공격 중 고정을 여러 위치와 벽 앞에서 확인한다.
- [x] 직전 효과음의 재생 요청과 타격 시작 사이 간격을 확인한다.
- [x] 3연격에서 유효타 중단, 3회 패링 스턴, 가드·빗나감의 스턴 미발생을 확인한다.
- [x] 스턴 해제·보스 처치·플레이어 사망·재시작과 잔여 코루틴 정리를 확인한다.
- [ ] 실제 청취로 기합1·기합2·비명1 및 발소리·공격 타이밍의 구별 가능성을 확인한다.
- [x] 기능명세에 실제 확인 결과와 미검증 항목을 구분해 기록한다.
- [x] WorkLog 기록 후 이 Task의 검증·수정 범위만 커밋하고 Task별 해시·검증 결과를 보고한다.

## 완료 조건

- 연결된 보스전 씬에서 PLAN_0007의 완료 조건을 실제로 확인한다.
- 테스트 코드·임시 검증 스크립트·새 검증 시스템을 만들지 않는다.
- 수행하지 못한 검증을 통과로 기록하거나 완료 커밋으로 처리하지 않는다.
- 필수 검증이나 사운드 연결이 미완료이면 보스전 씬 완성으로 보고하지 않는다.

상태: 전투 구현과 위 검증을 수행했으나 정식 음원 연결·실제 청취가 남아 전체 완료로 표시하지 않는다. 세부 수치와 검증 환경의 오류 기록은 보스전 기능명세에 기록했다.
