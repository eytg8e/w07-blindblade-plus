# TASK_0023 — 불필요한 순간 조명 제거

## 목표

- 외부 상호작용 변화: 감각 사건에서 실제 Point Light를 생성하지 않는다.
- 일반 Emit은 웨이브를, EmitFootstep은 발자국과 웨이브를 생성한다. 인지 사건 알림과 윤곽선 마스크를 유지한다.
- 삭제 대상: SensoryLightEffect.cs, SensoryLight.prefab 및 해당 meta. SensoryManager의 조명 참조·풀 준비·생성 처리도 제거한다.

## 구현 항목

- [x] 실제 조명 참조와 생성 경로를 제거한다.
- [x] 전용 코드·프리팹·meta를 삭제하고 남은 에셋 참조를 확인한다.
- [x] 필요한 컴파일 확인과 기능명세·WorkLog 갱신을 수행한다.

- 결과: 전용 에셋과 비어 있는 Resources/Sensory 폴더·meta를 삭제했다. 기존 발자국·웨이브·PerceptionRequested·인지 마스크와 남은 GUID를 보존했다.

- 실행하지 않은 플레이 검증은 미확인으로 기록한다.
