# TASK_0064 — 보스 피격 일시 퇴장

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 보스가 피격 후 잠시 공격 불가능한 위치로 사라지게 한다.

## 변경

- 피격 시 공격·이동을 취소하고 전투 공간 밖에서 잠시 피해를 차단한다.
- 복귀 시 중단한 패턴을 처음부터 재개한다.

## 구현 항목

- [x] 일시 퇴장 상태·위치·충돌체 비활성화·무적을 연결한다.
- [x] 복귀·종료 시 위치·충돌체·피해 수신을 복구한다.
- [x] 컴파일·퇴장 중 추가 피해 차단·복구를 확인한다.

## 완료 조건

- 퇴장 중 무한 사거리 및 직접 피해에도 체력이 감소하지 않는다.
- 즉시 배회로 전환하지 않고 복귀 시 중단한 패턴부터 재개한다.
