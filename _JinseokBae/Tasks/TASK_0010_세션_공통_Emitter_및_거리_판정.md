# TASK_0010 — 세션 공통 Emitter 및 거리 판정

## 목표

[PLAN_0002](../Plans/PLAN_0002_소리_충격_감각_표현.md)의 구현 단위 2을 수행한다. 여러 발생원의 요청을 처리하는 공통 Emitter와 관측자 거리 정책을 구성한다.

## 외부 상호작용 변화

- 발생원은 Game이 제공하는 공통 Emitter에 요청하고, Emitter가 시각 효과 생성 여부와 감쇠값을 결정한다.

## 구현 항목

- [x] 확정된 책임에 따라 Game에 공통 표현 담당 컴포넌트를 연결하고 읽기 전용 접근점을 제공한다. Managers에는 Emitter나 관측자 참조를 추가하지 않는다.
- [x] 기존 Game 및 MonoSingleton 구조를 유지하고 신규 싱글턴·정적 사건 버스·작은 중계 계층을 추가하지 않는다.
- [x] Emit 입력과 종류별 설정을 검증하고 관측자와의 거리를 생성 전에 판정한다. 최대 거리 이상은 모든 시각 효과를 생략한다.
- [x] 관측자 연결·교체·해제 API 및 세션 초기화·종료 경로를 맞춘다. 기존 Game이 씬 전환에도 유지됨을 고려해 이전 씬의 관측자 참조를 남기지 않는다.
- [x] 유효한 설정과 관측자가 없으면 원인을 보고하고 시각 요청을 거부한다. 자동 기본 객체 생성이나 설정 누락을 숨기는 처리를 하지 않는다.
- [x] Managers.Resource 및 Managers.Pool을 재사용하고 Managers의 기존 초기화·정리 계약은 변경하지 않는다. 실제 소리 재생을 거리 판정에 묶지 않는다.

## 완료 조건

- 여러 발생원이 같은 공통 담당자에 요청할 수 있고 담당자는 캐릭터 하나에 종속되지 않는다.
- 최대 거리 밖에서는 어떤 시각 효과도 생성되지 않으며 관측자 교체 후 새 기준이 즉시 적용된다.

## 검증

- Unity 참조 기반 C# 컴파일 및 연결 파일의 내부 참조 확인 완료. 실제 PlayMode 동작은 TASK_0013에서 미확인으로 관리한다.
