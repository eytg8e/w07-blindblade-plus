# TASK_0037 — 입력 어댑터 명시적 초기화

## 목표

PLAN_0005의 입력 어댑터 초기화 순서를 Initializer에서 직접 제어한다.

## 변경

- Game.SceneServicesChanged와 어댑터의 등록 변경 구독을 제거한다.
- Initializer가 씬 서비스 등록 후 활성 어댑터 Initialize를 호출하고 종료 시 Shutdown을 호출한다.

## 구현 항목

- [x] 씬 서비스 변경 이벤트 제거
- [x] 어댑터 명시적 초기화·정리 및 재활성화 처리
- [x] 컴파일 및 기존 Play 검증

## 완료 조건

- InputManager의 입력 정책 이벤트만으로 입력 허용 변경을 전달한다.
- 재초기화와 어댑터 재활성화에서 구독이 중복되지 않는다.
