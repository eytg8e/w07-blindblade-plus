# TASK_0070 — 보스전 발도 즉사 방지

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 보스가 발도 베기에 즉사하는 문제를 해결한다.

## 변경

- 발도 즉사를 인스펙터에서 선택하고 BossBattle에서는 일반 공격 피해량을 적용한다.

## 구현 항목

- [x] 시점 및 칼날 판정 양쪽에 즉사 설정을 적용한다.
- [x] BossBattle 플레이어의 즉사 설정을 끈다.
- [ ] Unity 컴파일을 확인한다.

## 완료 조건

- 보스 HP 200에 기본 피해 10을 적용하며 다른 씬의 발도 즉사 규칙은 유지한다.
