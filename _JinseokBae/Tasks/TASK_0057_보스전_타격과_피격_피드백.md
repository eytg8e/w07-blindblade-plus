# TASK_0057 — 보스전 타격과 피격 피드백

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 보스 적중·플레이어 피격을 확실한 효과와 소리로 전달한다.

## 변경

- 보스 실제 피해에는 접촉점 섬광·피격음을 표시한다.
- 플레이어 실제 피해에는 시야 앞 혈흔·다른 음높이의 피격음을 표시한다.

## 구현 항목

- [x] 기존 피해 이벤트와 풀을 재사용하는 보스전 효과를 연결한다.
- [x] 기존 효과의 보스전 전용 인지 예외 프리팹을 등록한다.
- [x] 보스 피격음과 플레이어 피격음의 음량·음높이를 씬에서 연결한다.
- [x] 컴파일·피해 이벤트·재생 연결을 확인하고 명세·WorkLog를 갱신한다.

## 완료 조건

- 실제 피해가 확정될 때 효과와 피격음이 한 번 요청된다.
- 가드·패링·헛스윙에는 피해 효과가 생성되지 않는다.
- 기존 체력·공격·보스 상태 규칙을 유지한다.
