# TASK_0051 — 보스 순간이동 연속 돌진

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 구현 단위 4를 달성한다. TASK_0050 완료 후 진행한다.

## 변경

- 플레이어 주변 랜덤 위치로 순간이동한 뒤 위치를 알리는 기합과 준비 시간을 거쳐 총 3회 돌진한다.
- 기존 박자 돌진의 이동 횟수와 이번 패턴의 반복 횟수를 혼동하지 않는다.

## 구현 항목

- [x] 플레이어 주변에서 장애물과 이동 경계를 고려한 유효한 순간이동 위치를 선택한다.
- [x] 매 순간이동 후 새 위치에서 기합1을 재생하고 준비 시간 뒤 돌진한다.
- [x] 단일 돌진 동작을 재사용해 총 3회 진행하고 각 돌진 사이에 대응 시간을 둔다.
- [x] 패턴 동안 보스 외형·발자국을 표시하며 순간이동 구간에 이동 흔적을 잘못 생성하지 않는다.
- [x] 배치 거리·준비 시간·돌진 간격을 설정으로 노출한다.
- [x] 유효 위치가 없거나 대상이 상실되면 피해 없이 안전하게 해당 진행을 중단한다.
- [x] 컴파일과 반복·취소 경로를 확인하고 기능명세·WorkLog 갱신 후 구현 변경을 커밋한다.
- [x] 반복 횟수·공간 재생 위치 연결·종료의 Play Mode 동작을 TASK_0054에서 확인했다.

## 완료 조건

- 서로 다른 유효한 위치에서 전조를 거친 돌진이 총 3회 실행된다.
- 순간이동 직후 방향을 들을 시간이 있고 벽 내부 배치·관통·전조 없는 공격이 없다.
- TASK_0049에서 확정한 적중·패링 종료 규칙을 적용하며 검증·커밋 후 다음 Task를 시작한다.
