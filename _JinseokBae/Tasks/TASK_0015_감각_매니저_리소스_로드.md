# TASK_0015 — 감각 매니저 리소스 로드

## 목표

[PLAN_0002](../Plans/PLAN_0002_소리_충격_감각_표현.md)의 공통 표현 담당자를 SensoryManager로 통일하고 Game이 리소스 프리팹을 생성하여 보유한다.

## 외부 상호작용 변화

- Game.SensoryManager로 공통 담당자에 접근하고 Game은 기존 Managers.Resource로 프리팹을 한 번 생성한다.
- 표시 설정은 리소스 프리팹에 연결하고 씬 관측자는 세션 시작 시 전달한다.

## 구현 항목

- [x] 클래스·접근점·호출부를 SensoryManager로 통일하고 스크립트 GUID를 유지한다.
- [x] 표시 설정을 연결한 Resources 프리팹을 구성하고 Game의 인스펙터 참조를 제거한다.
- [x] 테스트 씬의 직접 매니저 배치를 제거하고 시연에서 생성된 매니저에 관측자를 연결한다.
- [x] 컴파일·직렬화 참조 확인 및 기능명세를 갱신한다.

## 완료 조건

- Game 아래 매니저 한 개가 생성되고 기존 걸음·충돌·소리 발생원이 같은 인스턴스를 사용한다.
- 테스트 씬에 추가 수동 연결이 필요 없으며 실제 플레이 검증 여부를 명시한다.
