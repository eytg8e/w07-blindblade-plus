# TASK_0119 — 보스 체력바 지연 표시

## 목표

기존 보스 체력바에 즉시 값과 서서히 따라오는 값을 함께 표시한다.

## 외부 상호작용 변화

- 흰 바는 현재 HP를 즉시 반영하고 별도 색상 바는 이전 표시값에서 현재 HP까지 이동한다.
- 연속 HP 변경은 진행 중인 표시값에서 새 목표로 이어간다.

## 구현 항목

- [x] 기존 BossHealthBar에 지연 표시 이미지를 자동 생성한다.
- [x] 감소·증가 보간 및 초기화·비활성화 수명을 연결한다.
- [x] Unity 컴파일을 확인한다.

## 완료 조건

- 기존 보스 프리팹을 재사용하며 추가 연결 없이 동작한다.

- 검증: Unity 재컴파일 조회 up_to_date, 오류·경고 0건. 실제 플레이 외형은 미검증이다.
