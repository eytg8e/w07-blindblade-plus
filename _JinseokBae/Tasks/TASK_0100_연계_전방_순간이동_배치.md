# TASK_0100 — 연계 전방 순간이동 배치

## 목표

[PLAN_0008](../Plans/PLAN_0008_쌍둥이_보스.md)의 점프·사격 연계를 전방 순간이동으로 빠르게 시작한다.

## 변경

- 플레이어 수평 전방에 짐승을 가까이, 인간을 그 뒤에 배치한다.
- 기존 접근·후퇴·측면 이동을 제거하고 짐승 점프 후 짧은 간격으로 인간 사격을 잇는다.

## 구현 항목

- [x] 두 보스의 전방 지면·빈 공간·간격을 확인해 함께 순간이동하는 코드를 구현한다.
- [x] 접근·후퇴·측면 이동과 전용 설정을 제거한다.
- [x] 프리팹 전방 거리·뒤쪽 간격을 설정한다.
- [x] Unity 컴파일 오류·경고 0을 확인하고 기능명세·WorkLog를 갱신한다.
- [ ] 실제 플레이에서 전방 배치와 연계를 확인한다. 에디터 메인 스레드 시간 초과로 미확인이다.

## 완료 조건

- 두 보스 생존 시 연계 시작에 짐승 3m·인간 5m 전방 배치를 사용한다.
- 짐승 점프 완료 후 0.1초 뒤 인간 사격 전조를 시작한다.
- 유효한 두 위치가 없으면 연계를 생략하며 피격된 보스만 회피하는 규칙은 유지한다.
