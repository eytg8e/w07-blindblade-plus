# TASK_0081 — 배경 이펙트 캡처 분리

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 가까운 효과로 먼 배경이 함께 드러나는 문제를 수정한다.

## 변경

- 불투명 보스·환경을 특수 VFX 캡처에서 제외하고 일반 깊이 윤곽선으로 처리한다.

## 구현 항목

- [x] 환경 5곳 및 보스 몸체의 OutlineVFX 컴포넌트를 비활성화한다.
- [x] 열린 씬 저장 후 Play Mode에서 환경·몸체 6곳의 캡처 제외를 확인한다.

## 완료 조건

- 배경의 색상은 투명 효과 캡처에 섞이지 않으며 각 표면의 실제 깊이로 인지를 판정한다.
- 실제 발자국·공격 효과와 보스 외형 렌더러는 유지한다.
