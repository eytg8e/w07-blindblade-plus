# TASK_0022 — 위치·반경 기반 인지 마스크

## 목표

[PLAN_0003](../Plans/PLAN_0003_화면_공간_윤곽선_후처리.md)에 플레이어 주변 상시 인지와 소리 발생 지점 주변의 일시 인지를 추가한다.

## 변경

- 외부 상호작용 변화: Play 중 윤곽선을 관측자 주변과 유효한 감각 사건 주변에서만 표시하며 가장자리와 소리 수명을 페이드한다.
- SensoryManager는 기존 거리 판정에 통과한 사건을 알림으로 전달하고 같은 프리팹의 인지 컴포넌트가 관측자·반경·수명을 셰이더에 전달한다.
- 실제 조명·그림자·벽 차폐·파동 확산은 사용하지 않는다. 기존 효과와 생성 성공 반환값을 보존한다.
- 편집 모드에서는 전체 윤곽선을 미리 보고, Play 중에는 관측자가 없으면 인지 영역을 숨긴다.

## 구현 항목

- [x] SensoryManager의 거리 판정 뒤 사건 알림을 추가하고 기존 효과 처리를 보존한다.
- [x] 독립 인지 컴포넌트에 반경·수명·공간 페이드와 제한된 사건 버퍼를 제공하고 구독·해제 및 세션 정리를 적용한다.
- [x] 깊이로 복원한 월드 위치에 인지 마스크를 적용하고 중첩 영역의 최대 가시성을 사용한다.
- [x] SensoryManager 리소스 프리팹에 컴포넌트를 연결하고 기존 참조·GUID를 보존한다.
- [x] C# 컴파일과 기존 검증 수단으로 화면 동작을 확인하고 명세·WorkLog를 갱신한다.

- 검증: C# 컴파일과 Unity 재컴파일 완료, FootstepTest Play에서 인지 영역·사건 전달·발자국·웨이브 표시 및 새로운 사건 중지 후 1.5초 경과한 소리 영역의 사물 윤곽선 만료를 확인했다. 편집 모드로 복귀했고 씬 변경은 저장하지 않았다(isDirty=false).
- 미검증: 관측자 교체·해제·버퍼 초과·호환 모드·다른 해상도·대표 환경·성능. 검증 API의 Play 중 set_component_properties 거부 1건은 기능 오류와 구분한다.
- 수동 연결: 프리팹·셰이더 추가 연결 없음. 일반 게임 세션은 기존 SensoryManager.SetObserver(playerTransform)를 호출해야 하며 현재 FootstepTestDriver만 자동 연결한다.

## 완료 조건

- 관측자 주변은 상시 보이고 수신된 사건 주변은 시간에 따라 사라진다.
- 인지 영역 밖의 불투명 윤곽선은 숨겨지고 그림자와 재질 밝기는 판정에 영향을 주지 않는다.
- 관측자 해제·세션 종료·컴포넌트 비활성 시 과거 사건을 지운다.
- 구현·실행한 결과와 미검증 항목을 구분한다.
