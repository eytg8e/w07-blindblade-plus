# TASK_0053 — 보스전 프리팹과 씬 연결

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 구현 단위 6 중 보스전 씬 구성을 달성한다. TASK_0052 완료 후 진행한다.

## 변경

- 플레이어·보스·공통 초기화·충돌 환경을 갖춘 보스전 씬과 보스 프리팹을 연결한다.
- 기존 씬의 사용자 편집 내용을 덮어쓰지 않도록 새 보스전 씬 구성을 우선 검토한다.
- 기존 진입·라운드·문·승패 흐름 변경이 필요하면 수정 대상과 이유를 먼저 제안한다.

## 구현 항목

- [x] 적용 씬과 보스 프리팹 경로를 확정하고 공통 플레이어·세션 초기화와 연결한다.
- [x] 필요한 지면·이동 범위·충돌 환경과 플레이어·보스 시작 위치를 구성한다.
- [x] 보스 체력과 피해 판정·패링·행동·노출 참조를 연결하고 일반 적 제어의 중복을 제거한다.
- [ ] 기합1·기합2·비명1·각 칼질 직전 효과음·발소리의 실제 사운드 자산을 확인하고 연결한다.
- [x] 서로 다른 행동을 구분할 수 있는 자산이 없으면 누락을 명시하며 임의의 동일 소리로 완료 처리하지 않는다.
- [x] 배회 소리가 외형·발자국·감각 파동을 의도치 않게 드러내지 않게 연결한다.
- [x] 플레이어·보스의 기존 시각 효과 중 보스전에서 불필요한 연결을 확인해 씬·프리팹 범위에서 억제한다.
- [x] 보스 처치 후 공격 중지와 플레이어 사망 시 기존 게임오버·재시작 흐름을 연결한다.
- [x] 씬 접근과 빌드 포함을 확인하되 기존 진입 흐름의 무관한 변경은 하지 않는다.
- [x] 컴파일·씬 로드·필수 참조를 검증하고 기능명세·WorkLog 갱신 후 커밋한다.

## 완료 조건

- 보스전 씬을 열고 실행하면 추가 수동 연결 없이 전투가 시작된다.
- 지정된 외형·발자국 외에 새 UI·경고 표시·이펙트를 추가하지 않는다.
- 소리 자산과 필수 컴포넌트·프리팹 연결이 갖춰져 있고 누락을 숨기지 않는다.
- 저장되지 않은 편집 내용이나 동시 수정과 충돌하면 해당 파일 변경을 중지한다.
- 검증·커밋 후 통합 검증 Task를 시작한다.

검증: 컴파일 오류 0, 실제 씬 실행·NavMesh·패턴 순환·피해·노출을 확인했다. 정식 기합1·기합2·비명1은 자산이 없어 임시 피치 신호로 연결했고 정식 사운드 연결은 미완료다.
