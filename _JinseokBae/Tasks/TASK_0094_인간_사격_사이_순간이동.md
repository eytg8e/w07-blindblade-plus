# TASK_0094 — 인간 사격 사이 순간이동

## 목표

[PLAN_0008](../Plans/PLAN_0008_쌍둥이_보스.md)의 인간 단독 사격에 발사 간 재배치를 추가한다.

## 변경

- 첫 사격 뒤 기존 사격 간격만큼 기다리고 플레이어 전방 주변으로 순간이동한 뒤 다음 사격 전조를 시작한다.
- 탑승 협력 사격은 원형 이동을 유지하고 순간이동하지 않는다.

## 구현 항목

- [x] 인간 단독 사격 사이에 순간이동을 추가한다.
- [x] 반경·등장 각도·장애물 마스크를 인스펙터 설정으로 추가한다.
- [x] 빈 NavMesh 지면·완전한 경로·다른 위치를 검사하고 후보가 없으면 현재 위치에서 사격한다.
- [x] 컴파일 및 프리팹 설정을 확인하고 기능명세·WorkLog를 갱신한다.

## 완료 조건

- 단독 사격은 발사→간격→순간이동→전조→발사를 반복한다.
- 마지막 사격·탑승 중에는 순간이동하지 않고 사망·비활성화 시 기존 정리 수명을 유지한다.
