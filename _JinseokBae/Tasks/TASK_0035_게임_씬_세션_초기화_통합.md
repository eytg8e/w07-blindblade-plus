# TASK_0035 — 게임 씬 세션 초기화 통합

## 목표

PLAN_0005의 감각 초기화와 플레이어 발걸음 연결을 GameSceneInitializer에서 직접 관리한다.

## 변경

- MainMapSession의 공통 세션 기능을 Initializer로 통합한다.
- 미전환 씬의 MainMapSession은 초기화 진입용 호환 코드만 유지한다.

## 구현 항목

- [x] 감각 설정과 발걸음 구독·해제 이동
- [x] Initializer의 세션 컴포넌트 생성 제거
- [x] 미전환 씬 호환 및 기존 Play 검증

## 완료 조건

- 전환한 씬에서 MainMapSession 없이 공통 기능이 초기화된다.
- 미저장 씬 편집을 보존하고 기존 미전환 씬 진입이 유지된다.
