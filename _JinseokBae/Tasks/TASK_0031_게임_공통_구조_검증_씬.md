# TASK_0031 — 게임 공통 구조 검증 씬

## 목표

[PLAN_0005](../Plans/PLAN_0005_게임_씬_공통_구조_및_입력_관리.md)의 변경 사항과 책임 분리를 기존 컴포넌트로 직접 확인할 전용 씬을 만든다.

## 변경

- 생산용 플레이어·Initializer·서비스 프리팹을 사용하는 독립된 테스트 씬을 추가한다.
- 테스트용 서비스 Variant의 UI 버튼을 기존 입력·게임 상태 API에 연결한다.
- 기존 적 프리팹과 지형 기억을 배치하고 검증 절차 및 기대 결과를 기록한다.

## 구현 항목

- [x] 테스트 씬과 테스트용 서비스 Variant 생성
- [x] 입력 차단·허용·게임오버·재시작 버튼의 기존 API 연결
- [x] 현재 플레이어·서비스 중복·전투·지형 기억 API 실행 확인
- [x] 사용 안내와 실제 검증 결과 작성
- [ ] 실제 키보드·마우스 전체 이동 및 접근 교전 검증

## 완료 조건

- 새 테스트 코드를 작성하지 않고 공통 구조의 변경 의도를 직접 재현할 수 있다.
- 기존 미저장 씬과 생산용 코드·프리팹은 변경하지 않는다.
- 확인한 결과와 미확인 항목을 구분해 기록한다.
