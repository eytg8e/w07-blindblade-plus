# TASK_0123 — 대시 비네팅 가장자리 블러

## 목표

대시 집중선을 얇게 만들고 화면 가장자리로 갈수록 배경 블러를 증가시킨다.

## 외부 상호작용 변화

- 대시 중 중앙 화면은 선명하게 유지하고 바깥쪽 배경은 흐릿하게 표시한다.
- 집중선과 배경 블러 전체가 함께 페이드인·페이드아웃한다.

## 구현 항목

- [x] 집중선 폭과 표시 영역을 줄인다.
- [x] 기존 URP 배경 텍스처를 샘플링하는 가장자리 블러를 연결한다.
- [x] Unity 컴파일·셰이더·설정을 확인한다.

## 완료 조건
