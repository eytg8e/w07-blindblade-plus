# TASK_0007 — 발자국 테스트 씬 참조 복구

## 목표

[PLAN_0001](../Plans/PLAN_0001_발자국_시스템.md)의 테스트 씬과 프리팹을 Unity에서 실제로 로드하여 누락된 인스펙터 연결을 복구한다.

## 변경

- 별도 프로젝트 복사본에서 씬과 프리팹의 실제 직렬화 참조를 확인한다.
- 발자국 프리팹, 좌우 스프라이트, 링 및 관측자 참조를 복구한다.

## 구현 항목

- [x] Unity에서 실제 로드한 참조와 누락 원인 확인
- [x] 관련 씬·프리팹 연결 복구 및 GUID 보존
- [x] 기존 PlayMode 테스트 실행

## 완료 조건

- 테스트 씬과 프리팹의 필수 연결이 실제 Unity 객체로 로드된다.
- 확인한 실행 결과와 검증하지 못한 부분을 구분한다.

- 검증: 프로젝트 복사본에서 필수 참조가 모두 로드되는 것을 확인하고 씬·프리팹을 Unity 정식 저장 형식으로 보정했다. PlayMode 테스트 10개 통과 및 실제 테스트 씬 재생에서 이벤트 5회·활성 발자국 5개·오류 0건을 확인했다.
