# TASK_0005 — 발자국 이벤트 Game 이관

## 목표

[PLAN_0001](../Plans/PLAN_0001_발자국_시스템.md)의 전역 발자국 알림을 게임 세션 매니저가 소유하도록 변경한다.

## 변경

- Game의 인스턴스 이벤트가 발생 캐릭터 Transform과 지면 접촉 위치를 전달한다.
- FootstepEmitter는 접촉 정보를 Game에 전달하고 시연 및 테스트 구독자는 Game을 구독한다.

## 구현 항목

- [x] Game 이벤트 및 발행 API 추가, Emitter의 정적 이벤트 제거
- [x] 시연 및 기존 테스트의 구독·해제와 발생 캐릭터 검증 갱신
- [x] 관련 코드 컴파일 및 기능명세 갱신

## 완료 조건

- 발생 캐릭터와 위치가 Game 인스턴스 이벤트로 전달된다.
- 구독 해제 시 새 싱글턴을 생성하지 않으며 기존 시각 효과와 거리 정책은 유지한다.

- 검증: 게임 및 테스트 코드 컴파일 성공, 실제 PlayMode 실행 미확인.
