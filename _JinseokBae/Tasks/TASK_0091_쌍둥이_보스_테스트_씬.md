# TASK_0091 — 쌍둥이 보스 테스트 씬

## 목표

[PLAN_0008](../Plans/PLAN_0008_쌍둥이_보스.md)의 쌍둥이 보스를 독립된 테스트 씬에 배치한다.

## 변경

- 기존 BossBattle의 지형·NavMesh·플레이어·게임 초기화·BGM을 재사용한다.
- 새 씬에서는 기존 단일 보스와 전용 연결을 제거하고 쌍둥이만 배치한다.
- 두 보스의 임시 외형과 개별 체력바를 표시해 생존 조건별 패턴을 확인할 수 있게 한다.

## 구현 항목

- [x] TwinBossTest 씬과 메타를 생성하고 프리팹·플레이어 연결을 완료한다.
- [x] 테스트 씬의 개별 체력바·윤곽선 표시를 연결한다.
- [x] 빌드 목록에 새 씬을 추가해 같은 씬 재시작을 지원한다.
- [x] Unity 미리보기에서 보스·플레이어·체력바 수와 필수 참조·NavMesh·누락 스크립트 여부를 확인한다.
- [x] 기능명세와 WorkLog를 갱신한다.

## 완료 조건

- 새 씬에 쌍둥이·플레이어·지면·NavMesh·세션 초기화가 연결되어 있다.
- 기존 BossBattle과 쌍둥이 프리팹 원본은 변경하지 않는다.
- 실제 Unity 실행 여부를 구분해 보고한다.
