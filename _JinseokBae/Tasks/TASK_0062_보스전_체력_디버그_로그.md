# TASK_0062 — 보스전 체력 디버그 로그

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 플레이어·보스 체력 변화를 콘솔에서 확인한다.

## 변경

- 실제 체력 변화마다 변경 전·후·최대 체력을 개발용 로그로 출력한다.

## 구현 항목

- [x] 기존 HealthChanged 이벤트를 구독하고 비활성화 시 해제한다.
- [x] 에디터·개발 빌드에만 로그를 포함하고 같은 체력 값은 출력하지 않는다.
- [x] 컴파일과 실제 피해 로그를 확인한다.

## 완료 조건

- 플레이어·보스의 실제 체력 변화에 로그가 출력된다.
- 체력이 유지되는 가드·패링에는 체력 변화 로그가 없다.
