# TASK_0048 — 보스전 카메라 수평 회전

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 구현 단위 1을 달성한다.

## 변경

- 카메라 상하 회전을 제거하고 좌우 회전과 이동을 유지한다.
- `PlayerMotor`의 초기 각도, 시점 입력, 반동과 `ViewForward`를 함께 확인한다.

## 구현 항목

- [x] 상하 입력을 시점에 적용하지 않고 수평 시점 방향을 공격·방어에 전달한다.
- [x] 초기 각도와 카메라 반동에서도 상하 회전이 발생하지 않게 한다.
- [x] 기존 이동과 카메라 높이 변화는 유지한다.
- [x] 컴파일 및 상하·좌우 입력을 확인하고 플레이어 기능명세를 갱신한다.
- [x] WorkLog 기록 후 이 Task 변경만 커밋한다.

## 완료 조건

- 상하 입력·반동으로 위아래를 보지 않으며 좌우 회전은 정상 동작한다.
- 플레이어 공격·가드 방향이 수평 시점과 일치한다.
- 검증이 끝나고 Task별 커밋이 생성되어야 다음 Task를 시작한다.

검증: 대상 프로젝트 Unity 컴파일 오류 0. 격리된 프리팹에서 초기 기울기·입력·반동 처리 결과를 확인했으며 실제 Play Mode 입력은 TASK_0054에서 검증한다.
