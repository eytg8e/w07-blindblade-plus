# TASK_0076 — 보스 빠른 재배치 이동

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 패턴 위치 재배치를 순간이동 대신 빠른 이동으로 변경한다.

## 변경

- 돌진 전 위치 선정은 유지하며 NavMesh 경로로 이동한다.
- 정면승부 진입과 정면 추적도 연속 이동하고 기존 발소리·발자국을 사용한다.

## 구현 항목

- [x] 돌진 재배치의 Warp를 제거하고 빠른 경로 이동을 적용한다.
- [x] 정면승부 진입·추적을 빠른 연속 이동으로 변경한다.
- [x] 재배치 중 기존 발소리·발자국을 활성화한다.
- [x] Unity 컴파일 완료·실패 없음·오류 없음 확인.

## 완료 조건

- 이동 가능 경로로 재배치 후 돌진을 준비하며 실패 시 순간이동으로 대체하지 않는다.
- 피격 취소·일시 퇴장과 기존 공격 규칙을 유지한다.
