# TASK_0052 — 보스 정면승부 3연격과 스턴

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 구현 단위 5를 달성한다. TASK_0051 완료 후 진행한다.

## 변경

- 정면 준비 구간과 공격별 타이밍 소리로 3연격을 전달한다.
- 유효타 적중 시 중단하고 3회 모두 패링했을 때만 비명1을 동반한 스턴을 적용한다.
- 정면승부에는 별도 필요성이 확인되지 않은 외형·발자국 노출을 추가하지 않는다.

## 구현 항목

- [ ] 준비 중 플레이어의 수평 정면에 배치하고 기합2로 시작을 알린다.
- [ ] 각 칼질 시작 시 보스 위치·방향을 확정하고 실행 중 추종을 멈춘다.
- [ ] 각 공격 직전 효과음과 실제 피해 판정 사이의 설정된 간격을 유지한다.
- [ ] 개별 공격의 피해·가드·패링·빗나감 결과를 구분한다.
- [ ] 첫 유효타 적중 시 남은 타격과 소리 예약을 취소한다.
- [ ] 서로 다른 3타를 모두 패링한 경우 비명1 재생 후 외형을 드러내고 설정 시간 동안 정지한다.
- [ ] 스턴 종료 후 확정된 복귀 규칙을 적용하고 사망·비활성화 시 예약을 정리한다.
- [ ] 배치 거리·타격 간격·전조 간격·피해량·스턴 시간을 설정으로 노출한다.
- [ ] 실제 결과별 분기와 취소를 검증하고 기능명세·WorkLog 갱신 후 커밋한다.

## 완료 조건

- 이동·회전한 플레이어 앞에서 준비하지만 진행 중인 칼질은 끌려다니지 않는다.
- 유효타가 들어가면 남은 공격이 발생하지 않고 일반 가드·빗나감으로 스턴하지 않는다.
- 3회 패링 시 비명·외형 노출·정지가 발생하고 시간이 지나면 정상 복귀한다.
- 검증·커밋 후 다음 Task를 시작한다.
