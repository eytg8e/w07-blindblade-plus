# TASK_0017 — 공통 사건과 발자국 요청 분리

## 목표

[PLAN_0002](../Plans/PLAN_0002_소리_충격_감각_표현.md)의 공통 사건 데이터에서 발자국 좌우 정보를 분리한다.

## 외부 상호작용 변화

- SensoryEvent는 위치·법선·방향만 보유한다.
- Emit은 웨이브·빛을 재생하고 EmitFootstep은 좌우 인수를 받아 발자국을 함께 재생한다.

## 구현 항목

- [x] 공통 사건의 IsLeft와 생성자 좌우 인수를 제거한다.
- [x] 두 공개 재생 API가 공통 거리·풀·수명 처리를 공유하도록 연결한다.
- [x] 걸음 발생원 호출을 EmitFootstep으로 변경하고 컴파일·명세를 확인한다.

## 완료 조건

- 일반 요청에는 발자국이 생성되지 않으며 걸음 요청은 기존 세 효과를 한 번씩 생성한다.
- 기존 표시 설정과 씬·프리팹 연결을 유지한다.
