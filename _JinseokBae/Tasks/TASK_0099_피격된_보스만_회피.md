# TASK_0099 — 피격된 보스만 회피

## 목표

[PLAN_0008](../Plans/PLAN_0008_쌍둥이_보스.md)의 실제 피격 회피를 피해를 받은 보스에게만 적용한다.

## 변경

- 두 체력의 피격 사건을 구분하고 최초 피격 보스만 회피 대상으로 기록한다.
- 다른 보스는 공격·이동을 취소한 뒤 제자리에서 대기한다.
- 회피·회복 중 추가 피해는 회피 대상이나 시간을 변경하지 않는다.

## 구현 항목

- [x] 피격 대상 기록과 한 보스만 이동하는 회피를 구현한다.
- [x] 이벤트 구독·해제 및 대상 초기화를 맞춘다.
- [x] 컴파일과 양쪽 피격 동작을 확인하고 기능명세·WorkLog를 갱신한다.

## 완료 조건

- 짐승 피격은 짐승만, 인간 피격은 인간만 회피한다.
- 실제 피해·연계 취소·반사탄 파훼·생존자 패턴 선택은 유지한다.
