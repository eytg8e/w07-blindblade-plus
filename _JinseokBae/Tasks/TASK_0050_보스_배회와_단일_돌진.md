# TASK_0050 — 보스 배회와 단일 돌진

## 목표

[PLAN_0007](../Plans/PLAN_0007_사운드_중심_보스전.md)의 구현 단위 3을 달성한다. TASK_0049 완료 후 진행한다.

## 변경

- 숨겨진 보스를 공간 발소리로 추적하고, 제한 시간 동안 때리지 못하면 단일 돌진으로 대응하게 한다.
- 공격 성공의 보상은 피해 자체로 유지하며 추가 스턴은 넣지 않는다.
- 배회 중 피격 후 제한 시간의 재계산 규칙을 구현 전에 확정한다.

## 구현 항목

- [x] 이동 가능한 주변 위치를 선택해 배회하고 위치에 붙은 발소리를 재생한다.
- [x] 배회 중 외형·시각적 발자국을 숨기되 실제 공격 대상과 피해 수신은 유지한다.
- [x] 배회 제한 시간과 피격 결과로 단일 돌진 진입을 처리한다.
- [x] 기합1 → 준비 → 고정 방향 돌진 → 종료 흐름을 구현한다.
- [x] 돌진 중 외형·발자국을 표시하고 장애물·이동 경계를 고려해 실제 접촉에만 피해를 적용한다.
- [x] 배회 시간·돌진 준비 시간·속도·거리·피해량을 설정으로 노출한다.
- [x] 대상 프로젝트 컴파일과 코드 경로를 확인하고 기능명세·WorkLog 갱신 후 이 Task 구현 변경을 커밋한다.
- [x] 실제 배회·돌진·접촉 피해를 TASK_0054에서 확인했다. 실제 청취는 정식 음원 연결 후 확인한다.

## 완료 조건

- 보이지 않는 배회 보스의 위치를 발소리로 알 수 있고 공격 시 피해가 적용된다.
- 추가 피격 스턴 없이 확정된 타이머 규칙에 따라 돌진한다.
- 전조 없는 돌진, 장애물 관통과 동일 돌진의 중복 피해가 없다.
- 취소·종료 시 이동과 타격이 중지되고 검증·커밋 후 다음 Task를 시작한다.
