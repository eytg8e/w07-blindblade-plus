# TASK_0095 — 쌍둥이 피격 이펙트와 소리

## 목표

[PLAN_0008](../Plans/PLAN_0008_쌍둥이_보스.md)의 두 보스 실제 피격에 기존 타격 이펙트·소리를 연결한다.

## 변경

- 두 EnemyHealth.Damaged를 같은 효과 담당자가 구독하고 기존 BossDamageHit 풀을 재생한다.
- 플레이어 실제 피해는 한 번만 구독해 기존 PlayerDamageHit를 재생한다.
- 두 보스에 기존 EnemyDamageAudio를 연결한다.

## 구현 항목

- [x] 쌍둥이 전용 효과 담당자의 피해 구독·해제와 기존 효과 재생을 구현한다.
- [x] 프리팹의 두 체력·효과·피격 소리 연결을 완료한다.
- [x] Unity 컴파일 및 프리팹·테스트 씬 연결을 확인한다.
- [x] 기능명세·WorkLog를 갱신한다.

## 완료 조건

- 두 보스 실제 피해에 타격 섬광·소리가 연결되고 플레이어 피해 효과는 중복되지 않는다.
- 한쪽 사망 후에도 생존자와 플레이어의 피해 효과를 유지한다.
- 추가 인스펙터 연결 없이 기존 테스트 씬이 새 프리팹 구성을 상속한다.
