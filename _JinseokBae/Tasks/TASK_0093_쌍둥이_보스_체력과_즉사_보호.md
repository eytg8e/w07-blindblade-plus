# TASK_0093 — 쌍둥이 보스 체력과 즉사 보호

## 목표

[PLAN_0008](../Plans/PLAN_0008_쌍둥이_보스.md)의 두 보스가 한 번의 발도로 사망하는 문제를 수정한다.

## 변경

- 인간·짐승 최대 체력을 각각 100에서 300으로 높인다.
- 일반 적으로 분류되는 쌍둥이의 발도 즉사 적용을 막는다.

## 구현 항목

- [x] 두 보스 프리팹 체력을 300으로 변경하고 Unity에서 설정을 확인한다.
- [x] 공용 EnemyCombatService의 두 판정 변경에 대한 사용자 승인을 확인한다.
- [x] 시점·칼날 경로에서 쌍둥이 발도에 일반 공격 피해량을 적용한다.
- [x] Unity에서 두 프리팹 체력 300·즉사 옵션 해제 및 컴파일 오류·경고 0을 확인한다.
- [x] 기능명세·WorkLog를 갱신한다.

## 완료 조건

- 기본 상태의 인간·짐승이 체력 300을 사용하고 한 번의 발도로 즉사하지 않는다.
- 일반 적의 기존 즉사 규칙과 기존 보스 예외를 유지한다.
