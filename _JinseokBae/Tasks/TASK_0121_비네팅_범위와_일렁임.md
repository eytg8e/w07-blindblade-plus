# TASK_0121 — 비네팅 범위와 일렁임

## 목표

저체력 비네팅을 HP 80% 이하부터 표시하고 은은한 가장자리 움직임을 추가한다.

## 외부 상호작용 변화

- HP 80%에서 약하게 시작하고 HP가 낮아질수록 진하고 넓어진다.
- 가장자리 모양과 불투명도가 은은하게 일렁인다.

## 구현 항목

- [x] 시작 기준을 80%로 변경한다.
- [x] 셰이더 일렁임과 인스펙터 진폭·속도 설정을 연결한다.
- [x] Unity 컴파일·셰이더 상태를 확인한다.

## 완료 조건

- 기존 HP 사건과 프리팹 연결을 유지하고 추가 입력·피해 처리 변경 없이 동작한다.
