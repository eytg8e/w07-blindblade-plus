# TASK_0036 — 입력 정책 이벤트와 어댑터 책임 분리

## 목표

PLAN_0005의 InputManager는 정책만 관리하고 실제 플레이어 입력 정리는 기존 어댑터가 수행한다.

## 변경

- InputManager의 플레이어·모터·어댑터 참조를 제거하고 입력 허용 변경 이벤트를 제공한다.
- 두 어댑터는 씬 매니저 등록 및 입력 정책 이벤트에 연결하고 비활성화 시 해제한다.

## 구현 항목

- [x] 정책 이벤트와 씬 서비스 변경 알림
- [x] 어댑터별 구독 수명과 이동·시점·유지 입력 정리
- [x] 컴파일 및 기존 Play 검증

## 완료 조건

- InputManager가 플레이어 명령을 직접 호출하지 않는다.
- 입력 모드·UI 입력·게임오버·재시작 동작이 유지되고 구독이 중복되지 않는다.
