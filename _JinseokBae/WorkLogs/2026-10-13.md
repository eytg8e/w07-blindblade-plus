
## TASK_0115 — 음량 모달과 절단 복원

- 음량 버튼 절단 완료 후 검은 전체 화면 배경과 닫기 버튼을 자동 생성한 음량 UI를 열고 뒤쪽 메뉴 입력을 차단한다.
- 절단 완료 시 텍스트 숨김을 유지하고 음량 UI를 닫아 메인 메뉴로 복귀할 때만 이벤트로 텍스트와 메뉴 입력을 복원하며 Unity 컴파일·실제 화면은 미확인이다.

## TASK_0116 — 게임오버 재도전

- 재도전 TMP의 Raycast Target을 복구해 마우스 클릭이 부모 Button에 전달되도록 변경하고 실제 시간 기반 절단 후 기존 GameStateManager.Restart를 호출한다.
- Unity 컴파일 오류·경고 0건과 프리팹 연결을 확인했으며 실제 클릭·절단 외형·씬 재시작 플레이 검증은 미실행이다.

## TASK_0117 — 절단 연출 단축

- 인트로·재도전 기본 절단 시간을 0.35초에서 0.2초로 줄이고 인트로 씬 저장값에도 적용했으며 실제 화면 재검증은 미실행이다.

## TASK_0118 — 절단 타격감

- 인트로·재도전의 절단 조각에 초반 가속 분리와 순간 확대·축소·반대 방향 회전을 추가하고 강도를 인스펙터에 노출했다.
- Unity 컴파일 오류·경고 0건을 확인했으며 실제 화면 재검증은 미실행이다.

## TASK_0119 — 보스 체력바 지연 표시

- 보스 HP 사건에 즉시 반영하는 흰 바와 이전 표시값에서 현재 HP까지 따라가는 주황 바를 연결하고 연속 변화·재활성화·비활성화 수명을 관리한다.
- Unity 재컴파일 조회 up_to_date 및 오류·경고 0건을 확인했으며 실제 플레이 외형은 미검증이다.

- TASK_0119 색상 보완: 보스 프리팹과 쌍둥이 씬의 지연 바를 빨간색으로 저장하고 열린 BossBattle 컴포넌트에 RGBA(1,0,0,1)이 적용됐음을 Unity에서 확인했다.

- TASK_0119 속도 조절: 보스 지연 HP바의 추적 시간을 0.45초에서 0.8초로 늘리고 보스 프리팹과 쌍둥이 씬 저장값에도 적용했다.

## TASK_0120 — 저체력 비네팅

- 플레이어 프리팹에 HP 50% 이하에서 체력에 비례해 붉은 비네팅의 불투명도와 두께를 높이는 전용 컴포넌트·셰이더를 연결했다.
- Unity 컴파일 오류·경고 0건과 프리팹 연결·셰이더 지원 및 오류 없음 확인을 완료했으며 실제 플레이 외형은 미검증이다.

## TASK_0121 — 비네팅 범위와 일렁임

- 저체력 비네팅을 HP 80%부터 표시하고 셰이더 가장자리 두께·불투명도에 은은한 일렁임을 추가해 진폭·속도를 플레이어 인스펙터에 노출했다.
- Unity 컴파일 오류·경고 0건을 확인했으며 실제 플레이 체감은 미검증이다.

## TASK_0122 — 대시 집중선 비네팅

- 플레이어 프리팹에 대시·회피 중 흰 집중선을 표시하고 종료 페이드 및 사망·일시정지 시 숨기는 전용 컴포넌트·셰이더를 연결했다.
- 컴파일 조회 오류·경고 0건, 프리팹 연결과 셰이더 지원·오류 없음 확인을 완료했으며 실제 플레이 체감은 미검증이다.

- TASK_0122 외형 조정: 대시 집중선을 128개로 늘리고 폭을 줄이며 공간 그라데이션을 제거했고 Unity 컴파일 오류·경고 0건을 확인했다.

- TASK_0122 외형 재조정: 대시 집중선 개수·폭을 이전 값으로 복원하고 그라데이션 없이 선 길이를 줄였으며 Unity 컴파일 및 프리팹·셰이더 설정을 확인했다.

- TASK_0122 끝 모양 조정: 대시 집중선 폭을 중앙 쪽 끝으로 갈수록 가늘어지도록 수정했다.

- TASK_0122 표현 조정: 대시 집중선의 흐름·진입·종료 애니메이션을 제거하고 중앙 쪽 끝으로 갈수록 투명해지는 고정 표현으로 변경했으며 Unity 컴파일 오류·경고 0건을 확인했다.

- TASK_0122 전체 페이드: 고정 집중선의 전체 강도에 0.06초 페이드인·0.15초 페이드아웃을 적용하고 프리팹 설정 및 Unity 컴파일 오류·경고 0건을 확인했다.

## TASK_0123 — 대시 비네팅 가장자리 블러

- 대시 집중선 폭·표시 영역을 줄이고 기존 URP 배경 텍스처 기반 가장자리 블러를 전체 페이드에 연결해 플레이어 프리팹에 적용했다.
- 컴파일 조회 오류·경고 0건과 셰이더 오류 없음·배경 캡처 설정·프리팹 값을 확인했으며 실제 플레이 외형은 미검증이다.

- TASK_0123 블러 제거: 사용자 요청으로 배경 블러와 설정을 제거하고 얇은 집중선과 페이드를 유지했으며 Unity 컴파일 오류·경고 0건을 확인했다.
