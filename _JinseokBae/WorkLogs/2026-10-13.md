
## TASK_0115 — 음량 모달과 절단 복원

- 음량 버튼 절단 완료 후 검은 전체 화면 배경과 닫기 버튼을 자동 생성한 음량 UI를 열고 뒤쪽 메뉴 입력을 차단한다.
- 절단 완료 시 텍스트 숨김을 유지하고 음량 UI를 닫아 메인 메뉴로 복귀할 때만 이벤트로 텍스트와 메뉴 입력을 복원하며 Unity 컴파일·실제 화면은 미확인이다.

## TASK_0116 — 게임오버 재도전

- 재도전 TMP의 Raycast Target을 복구해 마우스 클릭이 부모 Button에 전달되도록 변경하고 실제 시간 기반 절단 후 기존 GameStateManager.Restart를 호출한다.
- Unity 컴파일 오류·경고 0건과 프리팹 연결을 확인했으며 실제 클릭·절단 외형·씬 재시작 플레이 검증은 미실행이다.

## TASK_0117 — 절단 연출 단축

- 인트로·재도전 기본 절단 시간을 0.35초에서 0.2초로 줄이고 인트로 씬 저장값에도 적용했으며 실제 화면 재검증은 미실행이다.

## TASK_0118 — 절단 타격감

- 인트로·재도전의 절단 조각에 초반 가속 분리와 순간 확대·축소·반대 방향 회전을 추가하고 강도를 인스펙터에 노출했다.
- Unity 컴파일 오류·경고 0건을 확인했으며 실제 화면 재검증은 미실행이다.

## TASK_0119 — 보스 체력바 지연 표시

- 보스 HP 사건에 즉시 반영하는 흰 바와 이전 표시값에서 현재 HP까지 따라가는 주황 바를 연결하고 연속 변화·재활성화·비활성화 수명을 관리한다.
- Unity 재컴파일 조회 up_to_date 및 오류·경고 0건을 확인했으며 실제 플레이 외형은 미검증이다.

- TASK_0119 색상 보완: 보스 프리팹과 쌍둥이 씬의 지연 바를 빨간색으로 저장하고 열린 BossBattle 컴포넌트에 RGBA(1,0,0,1)이 적용됐음을 Unity에서 확인했다.

- TASK_0119 속도 조절: 보스 지연 HP바의 추적 시간을 0.45초에서 0.8초로 늘리고 보스 프리팹과 쌍둥이 씬 저장값에도 적용했다.
