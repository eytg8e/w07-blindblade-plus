### 매니저 싱글턴

- 기능 설명: 공통 서비스와 게임 세션 매니저를 하나의 인스턴스로 유지한다.
- 동작 조건 및 처리 흐름: Play에서 MonoSingleton이 인스턴스를 등록하고 Managers는 풀·리소스·사운드·씬 서비스를, Game은 감각·이펙트 자식을 준비한다.
- 구현 상태: 구현 완료. 스크립트 재로드 뒤 런타임 서비스 복구 검증 완료.

#### 관련 코드

| 파일 경로 | 클래스 / 메서드 | 역할 |
| --- | --- | --- |
| Assets/Scripts/Utils/MonoSingleton.cs | MonoSingleton / Instance, InitializeSingleton | 인스턴스 등록과 중복 제거 |
| Assets/Scripts/Managers/Managers.cs | Managers / GetServices, InitializeSingleton, ClearServices | 공통 서비스 생성·복구·정리 |
| Assets/Scripts/GameManagers/Game.cs | Game / InitializeSingleton, OnEnable | 감각·이펙트 자식 재사용과 초기화 |

#### 연결 및 협업

- 연결된 기능: 감각 표현, FMOD 사운드 매니저, 검 애니메이션.
- 공유하는 코드 및 상태: Managers의 서비스 getter와 Game의 세션 매니저 참조를 게임플레이 코드에서 사용한다.
- 중복 또는 충돌 사항: 기존 사용자 FMOD 소스·캐시 변경은 유지한다.
- 승인 필요 사항 및 결과: 사용자가 보고한 오류 수정을 요청했고 A 자동 구현과 자동 커밋을 이미 승인했다.
#### Play 중 스크립트 재로드 복구 (2026-10-10)

- 초기화 완료 bool은 재로드 후 남지만 비직렬화 SoundManager·PoolManager 등의 참조는 사라질 수 있다. Managers는 서비스 참조까지 검사하여 재생성하고, OnEnable 및 서비스 getter에서 복구한다. 부분 초기화 종료도 안전하게 정리한다.
- Game은 InitializeSingleton과 OnEnable에서 기존 감각·이펙트 자식을 찾아 재사용한다. MainMapSession 재활성화 시 관측자와 초기화 상태를 복구한다. EnemyFootsteps·FootstepEmitter의 공격 컴포넌트 캐시는 OnEnable에서 다시 구성한다.
- 검증: C# 컴파일 오류 없음. StraightCorridor Play 중 EditorUtility.RequestScriptReload로 실제 재로드 후 Sound 서비스·SensoryManager 준비 상태, 플레이어 및 적의 발걸음 호출과 Play 종료를 확인했다. 해당 구간의 새 대상 예외·경고 0건. 재로드 시 기존 사운드 인스턴스와 풀의 런타임 상태는 이어받지 않고 서비스를 재생성한다.
