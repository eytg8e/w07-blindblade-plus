### 기능 이름

- 기능 설명: 소리로 위치와 공격 타이밍을 판단하는 보스전. 배회 피격의 보상은 피해 자체이고 3연격 전체 패링은 스턴으로 보상한다.
- 동작 조건 및 처리 흐름: 전용 BossController가 한 행동 흐름만 실행하고 기존 EnemyHealth·근접 칼날·카타나 피해 및 방어 결과를 재사용한다.
- 구현 상태: TASK_0048~0054의 전투·프리팹·씬 연결과 아래 통합 검증을 수행했다. 정식 사운드 연결과 실제 청취 검증은 미완료다.

#### 연결 및 협업

- 연결된 기능: [적 공격 패턴](적_공격_패턴.md), [카타나 전투 V2](카타나_전투_V2.md), [감각 표현](감각_표현.md).
- 공유하는 코드 및 상태: DamageContext의 공격자·PatternId와 현재 보스 타격 번호를 사용한다. 동일 타격의 중복 방어 결과는 한 번만 기록한다.
- 중복 또는 충돌 사항: 일반 적·플레이어 방어 로직은 수정하지 않는다. 보스 프리팹에 일반 추적 컨트롤러를 연결하지 않는다.
- 승인 필요 사항 및 결과: 사용자가 보스전 씬 완성까지 구현과 Task별 커밋을 요청했다. 별도 기존 씬 진행 구조 변경은 포함하지 않는다.

#### 검증

- TASK_0049: 대상 프로젝트 Unity 컴파일 오류·경고 0. 기존 피해 이벤트 및 EnemyMeleeAttack 상속을 통해 방어 인식과 종료 경로를 연결했다. 실제 교전과 사망·재시작 검증은 프리팹 연결 후 TASK_0054에서 수행한다.

#### 배회·단일 돌진 (TASK_0050)

- 배회는 플레이어 주변의 완전한 NavMesh 경로를 선택한다. 피격 시 마지막 피격 기준 7초(설정 가능)로 제한 시간을 재설정하며 추가 스턴은 없다.
- 돌진은 준비 소리 이후 방향을 확정하고 SphereCast와 NavMesh 경계를 적용한다. 이동 구간의 OverlapCapsule로 플레이어 접촉을 판정하며 한 돌진당 피해는 한 번이다.
- BossPresentation은 배회 소리와 돌진 발자국을 별도로 처리하고 돌진·정면승부·스턴 상태에서 연결된 Renderer를 표시한다. 일반 FootstepEmitter는 보스에 사용하지 않는다.
- 기합1은 현재 WarCry의 피치 0.85 임시 신호이며 정식 음원 연결은 미완료다. 실제 위치·청취·접촉 검증은 통합 검증으로 남긴다. 대상 프로젝트 컴파일 오류·경고 0.

#### 연속 돌진 (TASK_0051)

- 플레이어 주변 반경 6m(설정 가능)의 후보 위치를 최대 12회 확인하고 빈 NavMesh 위치로 이동한 후 매번 기합·준비·돌진을 수행한다. 총 3회이며 돌진 사이 간격은 0.7초(설정 가능)다.
- 유효 위치가 없으면 해당 연속 돌진을 종료한다. Teleported 이벤트로 걸음 누적을 비워 순간이동 구간에 발자국과 발소리를 만들지 않는다.
- 돌진 적중은 해당 돌진당 1회 피해만 적용하며 스턴이나 전체 연속 패턴 중단을 추가하지 않는다. 기존 방어 계약상 돌진은 근접 칼날 패링 대상이 아니다.
- 대상 프로젝트 컴파일 오류·경고 0. 반복 횟수·위치·취소의 Play Mode 검증은 TASK_0054에서 확인한다.

#### 정면승부·스턴 (TASK_0052)

- 정면 배치 후 기합2를 재생한다. 각 칼질 준비 중 정면을 유지하고 TryAttack 시 위치·방향을 확정한다. 칼날 전조 시작 때 공격 직전음을 재생한다.
- 플레이어 DamageReceived가 보스 근접 문맥이면 남은 타격을 취소한다. DefenseSucceeded에서 현재 타격을 한 번만 집계하며 일반 가드·빗나감은 패링 성공으로 세지 않는다.
- 3회 모두 패링하면 비명1과 외형 노출을 동반한 3초(설정 가능) 스턴 후 배회로 복귀한다.
- 정면승부 준비 중에는 에이전트의 Transform 갱신을 분리하여 NavMesh 경계와 관계없이 플레이어 정면에 배치한다. 보스 전용 센서와 근접 공격은 장애물 차폐를 적용하지 않으며 돌진은 별도 장애물 설정을 유지한다. 종료·취소 시 유효한 지면으로 돌아가 에이전트 설정을 복원한다.
- 기본 순환은 배회→단일 돌진→연속 돌진→정면승부→배회다. 기합2·비명1은 WarCry의 피치 1.25·0.55 임시 신호이며 정식 음원은 미연결이다.
- 컴파일 오류·경고 0. 실제 피해·패링 분기는 TASK_0054에서 확인한다.

#### 보스전 씬 (TASK_0053)

- 플레이어 칼은 표시하고 검기·시각 접촉 효과·디버그 오버레이·시각 발자국은 씬 인스턴스에서 억제하며 검 애니메이션·공격 판정·발소리는 유지한다. 보스 외형은 OutlineVFX의 인지 예외로 연결하되 Renderer 활성 여부는 보스 상태로 제어한다.

- 컴파일 오류 0, 씬 실행·NavMesh 연결·게임 세션 Playing을 확인했다. 실제 순환에서 단일 돌진과 연속 돌진의 준비 4회, 정면승부의 최초 피해 후 중단, 돌진 Renderer 1개·발자국 생성·배회 Renderer 0개를 확인했다.

#### 통합 검증 (TASK_0054)

- Unity CLI의 프로젝트 경로를 명시하고 기존 eval·플레이·화면 촬영 기능을 사용했다. 테스트 파일·임시 검증 스크립트는 생성하지 않았다. 결과 확인을 위한 입력·타격·방어는 플레이 중 기존 공개 API 및 행동을 호출했다.
- 카메라: 입력 (80, 200)을 시점 처리에 전달하고 반동 적용 후 yaw 9.60도, 카메라 로컬 회전 0도, ViewForward.y 0을 확인했다. 실제 마우스 장치의 수동 조작은 미검증이다.
- 패턴: 배회→단일 돌진→연속 돌진→정면승부의 순환과 한 순환에서 기합 준비 4회, 돌진 Renderer 1개·발자국 생성 및 배회 Renderer 0개를 확인했다.
- 3연격: 실제 칼날 충돌을 이용한 패링 3회에 피해 없이 스턴이 발생했다. 전체 순환에서 Stunned 21.9초→Roaming 25.0초로 약 3.10초 후 복귀했다. 기본 타격 전조 0.25초는 관측 실행에서 프레임 간격을 포함해 약 0.30초였다.
- 일반 가드: 타격 3회·가드 3회·패링 0회이며 체력은 73을 유지했고 스턴하지 않았다. 빗나감: 타격 3회·방어 0회·패링 0회이며 체력 73을 유지했고 스턴하지 않았다.
- 유효타: 방어하지 않은 정면승부의 첫 타에 12 피해가 적용되고 남은 공격이 실행되지 않았다. 플레이어의 실제 3타 공격 흐름에서 보스 체력이 200→180으로 감소했다.
- 장애물: x=12에서 벽 너머 x=15의 플레이어를 향한 돌진이 x=13.12에서 멈추고 NavMesh를 유지했으며 플레이어 체력은 100을 유지했다.
- 최종 프리팹 재로드에서도 돌진 장애물 마스크 -5·정면승부 마스크 0을 확인했다. 돌진은 동일한 x=13.12에서 정지하고 확인용 플레이어 체력 10000이 유지됐으며 이 실행의 신규 콘솔 오류·경고는 0이었다.
- 종료: 보스 처치 시 Dead·루트 비활성·코루틴 정리를 확인했다. 플레이어 사망 시 GameOver·시간 배율 0, 기존 Restart 후 BossBattle·Playing·시간 배율 1·플레이어 체력 100·보스 체력 200을 확인했다.
- 정면 배치: 플레이어의 위치·시점 변경에 따라 전조 시 보스 위치 (14.60, 0.08, 0.00), (-1.60, 0.08, 0.00), (3.00, 0.08, 1.40)을 확인했다. 벽 앞에서도 정면 배치를 유지하고 공격 도중 플레이어 이동·회전에 세 타 모두 위치가 고정됐다. 종료 후 NavMesh·updatePosition·updateRotation이 복원됐다.
- 최종 배치 수정 후 전체 순환을 다시 실행하여 3회 패링 스턴과 약 3.1초 뒤 배회 복귀가 여러 순환에서 유지됨을 확인했다.
- 시각: 최초 숨김 상태 촬영에서 검은 화면만 보였으며 무기·검기·디버그 오버레이가 없었다. 이후 사용자 요청으로 플레이어 칼 표시를 복구했으며 복구 후 화면 촬영은 미확인이다. 스턴 촬영에서는 지정된 보스 외형 윤곽선을 확인했다. FMOD 개발용 오버레이는 보스전 동안 숨기고 보스 객체 파괴 시 기존 설정을 복구한다.
- 컴파일: 최종 대상 프로젝트 컴파일 오류·경고 0. 재시작 후 해당 플레이의 콘솔 오류·경고 0. 이전 Play Mode 종료 과정에서 기존 UIManager.Shutdown의 Managers 생성 오류가 1회 기록되어 있으며 기존 매니저는 수정하지 않았다.
- 검증 환경 기록: 일부 도구 요청에서 도메인 리로드 중 연결 끊김·5초 타임아웃이 발생했다. 플레이 전환 과정에 스택 없는 Unity 내부 Transform assertion도 기록되어 있으며 보스 코드 발생 여부는 미확인이다. 마지막 순환 관측 시 현재 콘솔 오류는 0이지만 이 기록을 무오류 실행으로 숨기지 않는다.
- 미완료: 정식 기합1·기합2·비명1 자산 연결 및 실제 청취를 통한 구별·위치 인지 검증.

#### 공간 기준점 (TASK_0056)

- 사용자 요청으로 BossBattle 씬에 4m 간격 바닥 격자와 경계 윤곽선을 표시한다. 격자는 높이 0.18m의 시각 전용 메시로 기존 윤곽선 캡처에서 구분한다.
- SpatialLandmarks의 북쪽 단일 높은 기둥·동쪽 쌍기둥·남쪽 세 기둥·서쪽 아치를 방향 기준점으로 배치한다. 격자·주변 장식과 경계의 OutlineVFX는 인지 예외로 연결해 소리 여부와 관계없이 표시한다.
- 추가 장식 23개에 Collider가 없고 기존 지면·경계 Collider 및 NavMesh 자산을 유지한다. 각 장식 위치·크기와 격자 간격은 씬 Transform에서 조절한다.
- Play Mode 촬영으로 바닥 격자·경계·북쪽 기둥·플레이어 칼 표시를 확인했다. 런타임 장식 Collider 0개 및 NavMesh 연결을 확인했다. 실제 조작에 따른 위치 인지 체감과 나머지 방향의 화면 촬영은 미확인이다.

#### 타격·피격 피드백 (TASK_0057)

- BossBattleHitEffects는 EnemyHealth.Damaged와 PlayerHealth.DamageReceived만 구독하고 실제 피해에서 공용 EffectManager 풀을 호출한다. 보스 피해는 접촉점 섬광, 플레이어 피해는 카메라 앞 0.8m·아래 0.1m의 혈흔으로 구분한다.
- EffectId.BossDamageHit(7)·PlayerDamageHit(8)를 EffectLibrary에 등록하고 기존 Impact·BloodHit의 보스전 전용 프리팹 Variant를 연결한다. 표시 인지 예외와 비배율 시간을 설정하여 숨은 보스 적중 및 사망 시 시간 정지에서도 단발 표현을 재생한다.
- BossBattle 씬의 보스에 EnemyDamageAudio를 추가해 SwordHit 음량 1.1·피치 1.15를 재생한다. 기존 PlayerCombatAudio의 플레이어 피격은 음량 배율 1.4·피치 0.75로 설정한다. 같은 원본 피격 음원을 재사용하며 다른 씬의 기본 음량·피치를 유지한다.
