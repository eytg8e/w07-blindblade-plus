### 파동 연출

- 기능 설명: 별도 프리팹으로 링을 확산·페이드하고 독립 수명 종료 시 기존 풀로 반환한다.
- 동작 조건 및 처리 흐름: 공통 Emitter가 위치·회전으로 생성하고 가시성을 Play에 전달한다. 직접 호출 시 Play(visibility)는 프리팹 기본 설정을 사용한다.
- 구현 상태: 공통 가시성 API 연결과 컴파일 완료. 실제 PlayMode 검증 미확인.

#### 연결 및 협업

- 연결된 기능: [감각 표현](감각_표현.md)의 공통 Emitter가 현재 걸음 설정에 따라 독립 생성한다.
- 공유하는 코드 및 상태: 발자국 객체의 수명과 무관하며 각 재생은 자신의 코루틴을 가진다. 재재생·비활성화 시 기존 코루틴을 정리한다.
- 중복 또는 충돌 사항: 현재 Footsteps 폴더 위치와 기존 이름·GUID를 보존했다. 기존 시연의 직접 웨이브 생성 경로를 제거했다.
- 승인 필요 사항 및 결과: 사용자 요청으로 독립 효과와 공통 감쇠 정책을 연결했다.

#### 인스펙터 및 검증

- Ring Renderer에 링 스프라이트를 연결한다. Duration은 초, 반경은 미터, 원본 링 지름은 1 Unity 단위이다. 루트 +Y는 표면 법선이다.
- 기본 Play의 가시성은 0~1이다. 공통 재생도 프리팹의 수명·반경을 사용한다.
- 씬·프리팹 연결과 C# 컴파일은 확인했다. 실제 확산·거리 가시성·독립 수명 및 풀 재사용은 미확인이다.
