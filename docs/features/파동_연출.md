### 파동 연출

- 기능 설명: 임의의 위치에서 링을 확산·페이드하고 자체 수명 종료 시 풀로 반환하는 독립 연출이다.
- 동작 조건 및 처리 흐름: 외부 호출자가 별도 파동 프리팹을 생성한 뒤 Play(visibility)를 호출한다. 파동이 자신의 코루틴으로 반경과 알파를 갱신하고 Duration 종료 시 반환한다. 발자국 객체와 캐릭터 이동이 없어도 사용할 수 있다.
- 구현 상태: 독립 코드 및 프리팹 구성과 컴파일 확인 완료. 실제 PlayMode 실행은 미확인.

#### 관련 코드

| 파일 경로 | 클래스 / 메서드 | 역할 |
| --- | --- | --- |
| Assets/Scripts/Waves/FootstepWave.cs | FootstepWave / Play, AnimateWave | 자체 재생, 반경 확산, 페이드 및 풀 반환 |
| Assets/Resources/Wave/Wave.prefab | FootstepWave, Poolable, 링 렌더러 | 발자국과 별도 루트의 독립 파동 프리팹 |
| Assets/Scripts/Footsteps/FootstepTestDriver.cs | FootstepTestDriver / PlayWave | 테스트 시연에서 선택적 이벤트 연동과 파동 단독 재생 |

#### 연결 및 협업

- 연결된 기능: 기존 Managers.Resource.Instantiate로 생성하고 Play를 호출한다. 기존 풀을 사용하며 새 매니저나 중계 계층은 없다.
- 공유하는 코드 및 상태: FootstepObject와 FootstepEmitter에 직접 의존하지 않는다. 테스트 시연만 지면 접촉 이벤트를 구독하여 파동을 별도 생성한다.
- 중복 또는 충돌 사항: 기존 FootstepWave 클래스 이름과 스크립트 GUID를 보존하고 파일은 Waves 폴더로 이동했다. 발자국 프리팹의 GUID 및 좌우 참조도 유지했다.
- 승인 필요 사항 및 결과: 사용자 요청에 따라 파동을 독립 기능으로 분리했다.

#### 인스펙터 연결 및 호출

1. 파동 프리팹 루트에는 FootstepWave와 Poolable을 두고 Ring Renderer에 링 스프라이트 자식을 연결한다.
2. Duration은 초, Start Radius/End Radius는 미터이며 링 스프라이트 원본 지름은 1 Unity 단위 기준이다. 루트의 +Y가 표면 법선을 향하도록 생성 회전을 지정한다.
3. Play의 visibility는 0~1 가시성이며 기본값은 1이다. 발자국의 거리·수명과 연결되지 않으므로 호출자가 필요한 표시 정책을 결정한다.
4. 중복 Play는 기존 코루틴을 중단하고 처음부터 재생한다. 비활성화되면 코루틴을 중단하고 참조를 정리한다.
5. 테스트 씬의 Wave Prefab은 연결 완료했다. 접촉 시 파동 재생 체크박스로 연동을 끌 수 있고 단독 재생 버튼은 발자국 발생 여부와 무관하게 동작한다.

#### 검증

- 파동 프리팹의 루트 컴포넌트, Poolable과 링 참조 및 게임 코드 컴파일을 확인했다.
- 발자국 객체의 종료나 가시성 계산이 파동 재생 시간을 갱신하지 않는 것을 코드에서 확인했다.
- 이번 변경의 실제 재생 및 단독 풀 반환 실행 검증은 미확인.
