### 화면 공간 윤곽선

- 기능 설명: 검은 면과 배경 위에 깊이·노멀 경계를 표시하며 Play 중에는 위치·반경 기반 인지 마스크로 플레이어 주변과 소리 주변만 공개한다. 조명·그림자·재질 밝기는 가시성에 영향을 주지 않는다.

#### 연결 및 협업

- 연결된 기능: Unity 6000.0.55f1 / URP 17.0.4의 PC_RPAsset과 PC_Renderer. 기존 SSAO 유지.
- 공유하는 코드 및 상태: URP 깊이·노멀 텍스처와 SensoryManager.Observer, PerceptionRequested를 사용한다. 플레이어 전투용 IPlayerPerceptionProvider와 기존 감각 효과·재질 API는 변경하지 않는다.
- 중복 또는 충돌 사항: DefaultVolumeProfile의 OutlineVolumeComponent 참조 GUID는 Assets·Packages·Library/PackageCache의 meta에서 찾지 못했고 Enabled 값은 0이다. 동작하는 기존 윤곽선 코드와 Renderer Feature는 발견되지 않았다. 해당 항목은 수정하지 않는다.
- 승인 필요 사항 및 결과: 사용자가 전체 윤곽선 구현 후 플레이어 주변 상시 인지·소리 위치 주변 일시 인지·공간 및 시간 페이드 방식을 선택했다. 실제 조명 마스크·벽 차폐·파동 확산은 제외한다.
- 설정 위치: PC_Renderer > Screen Space Outline. 선 색상(알파는 밝기), 선 검출 폭 1~6 렌더 픽셀, 깊이 민감도 1~200, 노멀 민감도 1~20. 민감도가 높을수록 작은 차이를 검출한다. 활성 여부는 기존 Renderer Feature 체크박스를 사용한다.
- 인지 설정: SensoryManager 리소스 프리팹 > SensoryPerceptionMask에서 플레이어 반경 2m, 소리 반경 4m, 소리 수명 1초, 가장자리 페이드 0.75m를 조절한다. 반경은 3D 거리이며 반경 0은 해당 공간 공개를 끈다. 소리는 수명 동안 선형으로 흐려지고 중첩 영역은 최대 가시성을 사용한다. 동시 사건은 최대 16개이며 초과하면 가장 오래된 사건을 교체한다.
- 실제 연결: Game이 생성하는 매니저 프리팹에 컴포넌트를 연결했다. Awake에서 같은 객체의 SensoryManager를 캐싱하고 OnEnable/OnDisable에서 사건을 구독·해제한다. 관측자 교체는 기존 SetObserver(Transform) 계약을 따르고 미연결·세션 종료·비활성 상태에서는 영역을 지운다. 현재 자동 관측자 연결은 FootstepTestDriver에만 있으므로 일반 게임 세션은 SetObserver(playerTransform)를 호출해야 한다. 카메라를 플레이어로 임의 대체하지 않는다.
- 사건 계약: Emit와 EmitFootstep 모두 기존 거리 판정을 통과하면 PerceptionRequested(SensoryEvent)를 효과 생성 전에 발행한다. Position을 인지 중심으로 사용하고 기존 bool 반환값은 실제 효과 생성 성공 의미를 유지한다. 실제 소리 재생이나 새 소리 발생원을 추가하지 않는다.
- 표현 범위: 일반 불투명 월드와 배경은 기존처럼 검게 합성한다. 파티클은 기본적으로 원래 URP 표현을 유지하고, OutlineVFX가 붙은 효과만 윤곽선과 인지 마스크를 적용한다. 발자국·웨이브도 컴포넌트를 붙이지 않으면 기본 표현이다. 벽에 가려진 면은 표시되지 않으며 인지 반경 자체는 벽을 통과한다.

#### VFX별 적용 선택

#### 플레이어 검 상시 윤곽선

- 정지 시 검과 칼집은 흰색 윤곽선만 유지한다. 네 재질을 Opaque로 복구하여 원래 색과 면을 숨긴다.
- PlayerWeaponRig의 Renderer 네 개에 Rendering Layer Mask bit 30을 추가했다. 물리 Layer는 유지한다.
- ScreenSpaceOutlineFeature가 선택된 Renderer를 AlwaysVisibleOutlineMask.shader로 R8 마스크에 그리고, ScreenSpaceOutline.shader는 해당 픽셀에만 인지 마스크를 우회한다. 기존 깊이·노멀 윤곽선 계산은 유지한다. PC_Renderer의 Always Visible Mask Shader에 새 셰이더를 연결한다.
- 검증: Unity 컴파일 오류 없음. StraightCorridor Play 정지 화면에서 주변은 검고 검·손잡이·칼집은 흰 윤곽선만 나타남을 캡처로 확인했다. 호환성 렌더링 경로와 다른 씬 화면은 미확인이다.

- 2026-10-10 삭제 회귀 복원: 사용자 승인으로 PC_Renderer.asset, ScreenSpaceOutlineFeature.cs, ScreenSpaceOutline.shader 및 각 meta를 정상 커밋 04d70a517bac7d818281300d4e39be7ea763de83에서 그대로 복원했다. PC_RPAsset의 기존 렌더러 GUID 참조를 복구하며 현재 RP 설정과 씬은 변경하지 않는다. 전체 런타임 C# 외부 컴파일은 오류 없이 통과했고 meta GUID 중복이 없음을 확인했다. Editor 명령의 main thread timeout으로 재임포트·셰이더 컴파일·Play 화면 검증은 미확인이다.

1. 윤곽선으로 표시할 VFX 프리팹의 루트를 선택한다.
2. Add Component에서 `OutlineVFX` 또는 `Effects > Outline VFX`를 붙인다. 루트와 활성 자식 Renderer가 함께 대상이 된다. 자식별로 선택하려면 해당 자식에만 붙인다.
3. 컴포넌트를 비활성화하거나 제거하면 원래 표현으로 돌아간다. 활성 부모에 컴포넌트가 있으면 자식은 여전히 부모의 대상에 포함되므로 제외하려면 부모의 선택 범위를 분리한다.
4. 프리팹에 저장하면 이후 생성·풀 재사용 시에도 같은 선택을 사용한다. 효과 ID·재생 API·충돌 Layer를 변경할 필요는 없다. 캐릭터나 씬 전체 루트가 아니라 VFX 루트에 붙인다.

- 기본 GameObject Layer는 그대로 유지한다. 실제 Physics Layer와 프로젝트 Layer 목록은 변경하지 않는다. 내부 Rendering Layer의 31번 비트만 카메라 실행 동안 선택 표시로 예약한다. 기존 조명용 비트는 유지하고 카메라 종료 후 원래 마스크를 복원한다.
- 원본 머티리얼 에셋을 수정하지 않는다. 선택한 효과는 임시 복제 머티리얼의 큐만 2500으로 옮겨 윤곽선 전에 처리한다. 선택하지 않은 불투명 파티클은 임시 큐 3000으로 옮겨 기본 투명 효과와 함께 합성 후 표시한다. 원래 셰이더·색상·블렌딩·ZWrite 설정은 유지하고 종료 후 원본 참조와 큐를 복원한다.
- 선택 VFX는 원래 셰이더로 별도 타깃에 기록한 RGB의 밝기 차이로 윤곽선을 검출한다. RGB가 검정인 면은 알파가 1이어도 검출하지 않으며, 투명 기하의 깊이 차이를 윤곽선으로 사용하지 않는다. 최근접 기하 깊이는 인지 마스크에만 사용한다. 원래 투명한 재질은 임시 복제본의 DepthOnly·DepthNormals·DepthNormalsOnly 패스를 꺼 불투명 깊이·노멀 프리패스에서 제외한다. 어두운 RGB 출력은 Transparent Threshold 조정이 필요할 수 있다. 검은색만 출력하는 효과의 실루엣은 검출하지 못하며, 셰이더의 커스텀 정점 변형·겹친 투명 기하의 인지 깊이는 근사이다.
- 일반 월드의 윤곽선은 유지된다. 기본 VFX는 인지 마스크로 숨기지 않고 원래 URP 설정으로 표시한다. 선택 효과는 Play 중 인지 영역이 없으면 숨겨지고 편집 모드에서는 전체 윤곽선이 보인다.
- 카메라 실행 전에 활성 VFX를 수집하며 기본 불투명 파티클도 찾는다. 현재 PC_Renderer 단일 기본 카메라 구성에서 검증했다. 다중 렌더러·카메라 스택·XR·대량 동시 파티클 성능·호환 모드는 별도 검증이 필요하다.
- 선택 기능 검증: 같은 Multiple Slashes를 기본·선택 상태로 나란히 표시해 기본은 원래 분홍·푸른색, 선택한 것은 검은 면·흰 윤곽선으로 표시됨을 확인했다. 컴포넌트를 끄면 원래 표현으로 돌아왔다. 기본 불투명 파티클도 원래 녹색 표시를 유지했다.
- 선택 윤곽선 보정 검증: Multiple Slashes의 기본·선택 표시를 다시 비교하고, RGB=검정·알파=1인 가산 블렌딩 Quad에 OutlineVFX를 붙여 보이지 않는 면의 윤곽선이 생성되지 않음을 확인했다. C# 재컴파일 오류 0건, 데모 씬 Windows 빌드 오류 0건으로 성공했다. 경고 16건은 남아 있다. 비교 오브젝트와 카메라 변경은 저장하지 않았다.
- 두 효과의 GameObject Layer는 0으로 유지됐고 렌더 후 Rendering Layer Mask=1·원본 머티리얼 에셋 참조·큐 3000으로 복원됐다. Play에서 인지 영역이 없을 때 선택 효과는 숨고 기본 효과는 색상을 유지했다. 인지 영역을 켜면 선택 효과의 윤곽선이 표시됐다.
- 컴파일·셰이더 오류 0건, Windows 빌드 오류 0건으로 성공했다. 기존 Pipeline 안내·윤곽선 및 에셋팩 Shader Graph 경고 16건은 남아 있다. 검증용 오브젝트·컴포넌트·임시 카메라 설정은 씬에 저장하지 않았고 isDirty=false를 확인했다. 기존 PC_Renderer·PC_RPAsset·이펙트 프리팹과 머티리얼은 변경하지 않았다.
- 한계: 평면 재질 경계·깊이/노멀을 기록하지 않는 재질·서브픽셀 디테일은 검출되지 않는다. 노멀 맵과 급한 깊이 변화는 잡음을 만들 수 있다. 렌더 스케일/업스케일링과 후속 AA·후처리 때문에 최종 표시 선 폭은 달라질 수 있다. Overlay 카메라에서 그린 월드는 적용 대상이 아니다.
- 검증: 기존 Unity 컴파일 응답 파일로 C# 컴파일 통과 후 대상 에디터 API 재컴파일 완료(오류 0건). FootstepTest 정지 카메라 1280×720 캡처에서 셰이더 실행, 실루엣·내부 경계, 선 폭 1→3 변경, 비활성 시 기존 화면 복귀를 확인했다. 기본 활성 true·폭 1로 복원했다. Play 모드·다른 씬·가려진 면·이동·다른 해상도·감각 효과 수명·호환 모드·빌드·성능은 미확인이다.
- TASK_0022 검증: C# 컴파일 및 대상 Unity 재컴파일 완료. FootstepTest Play에서 관측자 주변의 제한된 표시와 소리 주변의 사물 윤곽선·발자국·웨이브 표시를 확인했다. 시연 이동과 걸음 발생을 런타임에서 멈춘 뒤 같은 사물 위치(z=3.596653m)에서 1.5초 경과 후 소리 영역의 사물 윤곽선이 사라짐을 확인했다. 편집 모드 복귀 및 씬 isDirty=false를 확인했다. 기능 관련 실행 오류는 없으며 검증 도구의 set_component_properties가 Play 중 지원되지 않아 거부된 진단 오류 1건은 별도로 기록한다. 관측자 교체·해제·버퍼 초과·호환 모드·성능·대표 환경은 실행 검증하지 않았다.
