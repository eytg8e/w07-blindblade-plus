# 튜토리얼 안내

- 기능 설명: TutoStage의 기존 복도 동선에서 독백 힌트와 바닥의 3D 키 홀로그램으로 현재 플레이어 기능을 안내한다.
- 동작 조건 및 처리 흐름: 게임 세션이 Playing으로 준비된 후 안내 영역에 들어가면 기존 MonologueUI에 힌트를 표시한다. Resume Input이 지정된 구간은 시간과 플레이어 입력을 일시정지하고 지정 키의 새 입력까지 대기한다. 지정 키를 누르면 독백을 숨기고 기존 시간·입력 상태를 복구한 뒤 같은 명령을 즉시 전달한다. Resume Input=None인 일반 독백은 기본 6초 동안 표시하고 숨긴다. 문구가 없는 문 안내는 독백을 호출하지 않는다. 같은 지점 재안내 간격은 8초다. 실제 플레이어 행동이 확인되면 완료 상태를 기록한다.
- 구현 상태: 현재 배치 순서에 맞춘 01~07번의 7개 키 표시를 배치한다. 독백은 1→2→3→5→6→7 순서로 각 한 문장이고, 4번 문은 대사 없이 F만 표시한다. 안내 완료 여부로 통행이나 전투를 막지 않는다. 독백에는 단축키 이름을 넣지 않는다.

- Player의 시작 위치를 (0, 0, -12.4)로 옮겨 첫 안내가 화면 안에 들어오고 복도 입구에서 순서대로 접근하도록 했다.

## 직접 편집하기

1. Hierarchy의 Tutorial_Guide에서 TutorialGuide를 선택한다.
2. Lessons 배열 각 항목의 Monologue에서 독백을, Keys에서 홀로그램의 단축키를 수정한다.
3. 각 구간 자식 오브젝트의 위치와 BoxCollider Center/Size로 안내가 시작되는 위치를 조절한다. BoxCollider는 영역 검사에만 사용하며 Trigger로 유지한다.
4. Line Duration은 한 문장 표시 시간, Revisit Interval은 같은 지점에서 다시 독백을 시작할 간격이다.
5. Visibility Distance는 키가 보이는 거리(현재 4.3m), Key Height는 바닥에서 키까지 높이(1.05m), Float Amplitude/Speed는 부유 폭과 속도다.
6. Key Color/Completed Color와 두 전용 머티리얼로 색을 조절한다. 머티리얼은 어두운 씬에서 읽히도록 Unlit/Transparent를 유지한다.
7. 입력을 바꾸면 InputManager 및 PlayerInteraction의 실제 매핑을 확인하고 Keys 문구도 함께 갱신한다. Keys 텍스트는 입력 기능을 자체 변경하지 않는다.
8. 환경 콜라이더를 크게 변경하면 Tutorial_Guide의 NavMeshSurface를 다시 베이크하고 씬/이동 데이터를 저장한다.

## 연결 및 협업

- 기존 Game.Player, GameStateManager, MonologueUI, UIManager를 재사용한다.
- PlayerController.ActionEvent의 AttackStarted/DashStarted를 관찰한다. KatanaCombatCoordinator.EventRaised의 GuardStarted/GuardEnded/ParrySucceeded/NormalStarted를 관찰한다. 공격·패링 판정을 직접 생성하거나 수정하지 않는다.
- 이동·웅크리기·회피는 PlayerMotor의 공개 상태, 문 완료는 연결된 JapaneseSlideDoor.IsOpen으로 확인한다.
- 완료 상태는 이 플레이 세션에서만 유지하며, 재시작하면 초기화된다. 동일한 목표가 여러 안내에 사용되면 관련 완료 상태가 함께 갱신된다. 색상은 계속 흰색이다.
- MonologueUI는 한 화면을 공유하므로 이 씬에 다른 독백 발행자를 추가할 때는 표시 소유권을 협의해야 한다. 현재 튜토리얼 발행자는 TutorialGuide 한 개다.
- 이 씬 변경과 신규 튜토리얼 파일 추가는 사용자의 현재 열린 씬 작업 요청으로 승인되었다.
- 비활성화된 차지 공격, 확인되지 않은 웅크리기 은신 효과 및 미구현 기술은 안내 대상에서 제외했다. 현재 씬 Player에 PlayerStamina가 없어 스태미나 기믹은 확정된 동작처럼 설명하지 않는다.

## 검증과 제한

- Unity 컴파일 오류 0건. 현재 7개 키 표시의 참조, 독백 6개의 단일 문장, 문 안내의 빈 독백 및 동선 순서에 맞는 영역 선택을 확인했다.
- 최초 Play에서 한글 독백 표시, 자동 페이지, 월드 키 표시를 확인했다. 이후 사용자 요청으로 키와 바닥 링·빛 기둥, 완료 색상을 모두 흰색으로 변경했다. 독백 UI와 단축키는 별개다.
- 런타임의 실제 플레이어 명령으로 웅크리기, 회피, 일반 공격, 가드에서 공격 전환 시 확인 표시가 바뀌는 것을 확인했다.
- 실제 PlayerInteraction과 같은 카메라 레이 경로가 미닫이문 IInteractable을 찾는 것과 Interact 이후 문 열림/안내 완료를 확인했다. 화면 문 단축키는 숨겨진 것을 확인했다.
- NavMesh 정점 80개 및 기존 적의 NavMeshAgent.isOnNavMesh=true를 확인했다.
- 검증 중 InputManager와 적을 일시 비활성화한 상태에서 안내 확인을 수행했다. 이 변경은 Play 상태에만 적용했고 종료하여 복구했다. 백그라운드 업데이트 설정도 확인 후 원래 값으로 복구했다.
- 실제 물리 키 입력, 실전 적 공격에 맞춘 패링 성공, 전체 연계 콤보 및 계단 이후 씬 전환의 전체 통과 검증은 미확인이다.
- 기존 FMOD 포트 9264 사용 경고와 TMP 폰트 importer의 inconsistent result 경고가 기록되었다. 런타임 오류는 발생하지 않았다. FMOD 자체 디버그 창은 설정에 따라 계속 보인다.
- 테스트 코드, 공유 전투 코드, 입력 규칙 변경 및 Git CLI/커밋은 수행하지 않았다.
