# 보스 사망 씬 전환

- 기능 설명: BossBattle의 보스 1명 또는 TwinBossBattle의 보스 2명이 모두 사망하면 약 4초 뒤 다음 활성 빌드 씬으로 이동한다.
- 동작 조건 및 처리 흐름: BossSceneExit가 지정된 EnemyHealth.Died를 구독한다. 단순 비활성화나 일반 적 사망은 완료로 판단하지 않는다. 마지막 보스 사망 후 2초 대기하고 2초 페이드아웃한 뒤 현재 buildIndex+1 씬을 비동기로 로드한다. 대상 씬의 SceneTransitionFade가 검은 화면에서 2초 페이드인한다.
- 구현 상태: BossBattle·TwinBossBattle에 사망 감지와 페이드를 배치했다. Stage_3·EndingScene에도 전환 진입용 페이드를 배치했다. 도착 페이드 동안 EndingScene 대사 진행 입력은 대기한다.

## 관련 코드

| 파일 경로 | 클래스 / 메서드 | 역할 |
| --- | --- | --- |
| Assets/Scripts/Maps/BossSceneExit.cs | HandleDeath, Transition | 실제 보스 사망 및 다음 빌드 씬 이동 |
| Assets/Scripts/UI/SceneTransitionFade.cs | RequestEntry, FadeIn, FadeOut | 씬 간 검은 오버레이와 진입 페이드 |

## 연결 및 협업

- 빌드 순서: IntroScene → Stage_1 → Stage_2 → BossBattle → Stage_3 → TwinBossBattle → EndingScene. 사용자가 이 순서를 지정했다.
- 씬 경로: IntroScene·EndingScene은 Assets/Scenes/IntroEndingScene, 나머지는 Assets/Scenes/Build 아래의 씬을 사용한다.
- 기존 보스 전투·체력·피해 계산은 변경하지 않는다. 전환 컴포넌트는 보스 루트 밖에 있어 사망으로 보스가 비활성화되어도 계속 실행된다.
- 기본 전환 지연 4초 안에 2초 페이드아웃을 포함한다. 시간은 unscaled 시간을 사용한다. 출발 페이드 중 게임 입력을 차단하고, 게임오버·재시작 상태에서는 씬 전환을 취소한다.
- 진입 페이드 시 게임 세션이 준비되어 있으면 시간·입력·플레이어 상태를 보관해 일시정지하고 완료 후 복구한다. 보스 씬은 직접 진입해도 페이드인하며, Stage_3·EndingScene은 해당 전환 요청이 있을 때만 페이드인한다.
- Inspector의 Bosses, Transition Delay, Fade Out Duration, Fade In Duration으로 연결과 시간을 조절한다.

## 검증 및 제한

- Unity 편집 상태에서 BossBattle의 보스 1명과 TwinBossBattle의 보스 2명을 찾아 참조를 연결했다. 4개 씬과 요청한 빌드 목록을 저장했다. 원래 활성 씬으로 복귀했다.
- Unity 컴파일 확인을 수행한다. 사용자 지침에 따라 Play Mode·플레이 테스트·화면 캡처는 수행하지 않으며 실제 전투 후 이동은 미확인이다.
