### 인트로 메뉴

- 기능 설명: 기존 인트로 UI의 게임 시작, 전체 음량 조절, 종료 버튼을 연결한다. 위치, 크기, 색상, 폰트와 기존 프리팹 형태를 유지한다.
- 동작 조건 및 처리 흐름: IntroMenu에 기존 버튼과 음량 패널/슬라이더 참조를 연결한다. Awake에서 저장 음량을 복원하고 패널을 닫는다. 게임 시작은 Inspector의 씬 이름을 사용하고 볼륨 버튼은 패널을 토글한다. 슬라이더는 0~1 음량을 즉시 반영한다. 종료는 빌드에서 앱 종료, Editor에서 Play Mode 종료다.
- 구현 상태: 스크립트 컴파일과 Editor 참조 연결 완료. 빌드 씬은 IntroScene → SampleScene 순서다. 게임 시작 버튼의 SampleScene 전환, 음량 패널 토글, 0.37 음량 반영과 0 음소거, Editor 종료 버튼 콜백을 Play Mode에서 검증했다. 기존 Transform/RectTransform의 위치, 회전, 크기, 스케일, 앵커, 피벗이 연결 전후 동일했다. 독립 실행 빌드 종료와 실제 음원의 청취 검증은 미확인이다.

#### 연결 및 협업

- 연결된 기능: Managers.Sound.BgmVolume / EffectVolume, AudioListener.volume, SceneManager.LoadScene, PlayerPrefs.
- 공유하는 코드 및 상태: 슬라이더 값은 0~1이며 두 FMOD Bus 음량에 함께 적용한다. IntroMenu.Volume 키로 저장한다. 다른 씬에서는 유지되는 Managers.Sound와 AudioListener 음량을 사용한다.
- 중복 또는 충돌 사항: 공통 Managers와 SoundManager 코드는 수정하지 않는다. 기존 IntroMenu의 미구현 기능을 사용자 요청 범위 안에서 완성한다.
- 승인 필요 사항 및 결과: 사용자가 자동 구현과 기존 형태 보존을 요청했다. 목적 씬은 현재 빌드 목록의 SampleScene을 기본으로 사용했다. Canvas의 IntroMenu에서 Game Scene Name을 변경하고 대상 씬을 빌드에 등록하면 변경할 수 있다.
