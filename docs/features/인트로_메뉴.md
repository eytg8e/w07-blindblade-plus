### 인트로 메뉴

- 기능 설명: 기존 인트로 UI의 게임 시작, 전체 음량 조절, 종료 버튼을 연결한다. 시작·종료는 IntroMenu, 음량 UI는 VolumeControlUI가 담당한다. 기존 음량 프리팹을 사용하고 슬라이더는 메뉴 아래 중앙에 배치한다.
- 동작 조건 및 처리 흐름: IntroMenu에 시작·종료 버튼을 연결하고, 같은 Canvas의 VolumeControlUI에 볼륨 버튼과 음량 패널/슬라이더를 연결한다. Awake에서 저장 음량을 복원하고 패널을 닫는다. 게임 시작은 Inspector의 씬 이름을 사용하고 볼륨 버튼은 패널을 토글한다. 슬라이더는 0~1 음량을 즉시 반영한다. 종료는 빌드에서 앱 종료, Editor에서 Play Mode 종료다.
- 구현 상태: 메뉴 버튼과 음량 연결 기록은 남아 있다. 현재 IntroScene은 `Assets/Scenes/IntroScene/IntroScene.unity`에 있고 빌드 목록에 등록되지 않았다. 시작 버튼은 존재하지 않는 `SampleScene`을 가리키므로 현재 씬 전환은 실패한다.

#### 연결 및 협업

- 연결된 기능: Managers.Sound.BgmVolume / EffectVolume, AudioListener.volume, SceneManager.LoadScene, PlayerPrefs.
- 공유하는 코드 및 상태: 슬라이더 값은 0~1이며 두 FMOD Bus 음량에 함께 적용한다. IntroMenu.Volume 키로 저장한다. 다른 씬에서는 유지되는 Managers.Sound와 AudioListener 음량을 사용한다.
- 중복 또는 충돌 사항: 공통 Managers와 SoundManager 코드는 수정하지 않는다. 기존 IntroMenu의 미구현 기능을 사용자 요청 범위 안에서 완성한다.
- 승인 필요 사항 및 결과: 과거에는 SampleScene을 목적 씬으로 사용했다. SampleScene 파일이 현재 없어 실제 시작 대상과 빌드 등록을 다시 정해야 한다.

- 이번 검증: 씬의 컴포넌트·버튼·패널·슬라이더 참조와 0~1 범위를 파일에서 확인했다. 슬라이더는 기준 해상도 1920×1080에서 중앙 아래 260, 크기 420×32, 배율 1로 배치했다. Unity 컴파일·실제 화면·음량 조작 검증은 미실행이다.

- 연결 오류 수정: 열린 IntroScene에서 VolumeControlUI의 세 참조 누락을 확인하여 볼륨 버튼·패널·슬라이더를 직접 연결하고 씬을 저장했다. Unity SerializedObject 조회로 세 참조와 저장 상태를 확인했으며 플레이 검증은 미실행이다.

- 음량 패널 스타일: 중앙 아래 360 위치의 RectTransform 컨테이너에 520×180 어두운 카드, 얇은 금색 테두리, 전체 음량 제목과 작게/크게 라벨을 배치하고 슬라이더를 금색으로 정리했다. Play Mode에서 볼륨 버튼의 패널 표시를 확인하고, 촬영 시에만 카메라 캔버스로 전환하여 시각 확인 후 원래 Overlay 모드로 복원했다.
