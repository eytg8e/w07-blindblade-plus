- 기능 설명: Player@KatanaSlash_1의 사용자가 수정한 시작·끝 자세는 보존하고, 중간 베기를 기존 PoseAligned/IaidoDoubleSlash의 같은 시각 위치·회전으로 복원한다.

#### 2026-10-12 2타의 무게감과 연계 리듬 조정

- 기존 2타는 적중 진행도 0.75·적중 시간 0.22초로 주된 베기가 약 0.088초에 재생되고 베기 끝 자세와 적중 기준이 어긋났다. 1타의 해당 베기 구간은 약 0.192초였다.
- 2타의 시작은 1타 5번 프레임 그대로다. 준비는 0~2프레임, 반전 베기는 2~5프레임, 감속은 5~6프레임, 복귀는 6~10프레임으로 조정했다. 베기 중 원본 1타 위치·속도 커브를 동일 시각에 반전해 사용한다. 끝 자세·Scale·GUID·비반복 재생을 유지한다. 수정 전 백업은 `Temp/KatanaSlash2/before_20261012_033521.anim`이다.
- `KatanaWeaponVisual`의 `교체 2타에 1타 타이밍 사용` 기본값은 체크다. 1·2타 슬롯이 모두 있는 경우 2타 적중 진행도는 1타 설정을 사용한다. 일반 2타의 실제 적중·종료 시간과 베기 판정 폭도 PlayerActionDriver의 1타 설정을 사용한다. 해제하면 기존 2타 시간·적중 진행도를 사용한다. 반격 타이밍은 별도 설정을 유지한다.
- 현재 일반 연계의 양쪽 적중 시간은 0.32초, 전체 시간은 0.6초, 적중 진행도는 0.5다. 2타 준비 약 0.128초·주된 베기 약 0.192초·감속 약 0.056초·복귀 약 0.224초다. 1타 5번 프레임에서 2타로 바로 이어지는 전환과 중복 납도 방지를 유지한다.
- 생성기 메모리 컴파일·실행과 Unity 코드 컴파일 성공. 렌더한 시작·준비·베기 끝·복귀 이미지를 직접 확인했다. `NewAnimationTest` Play에서 2타 진행도 0.204에 약 0.131초, 0.501에 약 0.320초, 종료에 약 0.600초를 기록했다. 시작 위치 연속성과 종료 후 `Rest` 전환, 별도 `SheatheStarted` 미발생도 확인했다. 기록은 `Temp/KatanaComboReview/second_weight.txt`다. 최종 Console 오류 0개. 런타임 이동만 잠시 비활성화하고 Play를 종료했으며 씬·프리팹은 저장하지 않았다. 실제 적 피해·대상 돌진·물리 마우스 조작·주관적 타격감·빌드는 미확인이다.

#### 2026-10-12 1타 5번 프레임에서 2타 연결

- 교체 1타·2타 슬롯이 모두 연결된 일반 공격에서는 1타 중 추가 클릭 하나를 초반부터 예약한다. `1단 공격만 허용`이 켜진 경우에는 기존 단일 1타 반복 모드를 유지한다.
- 기존 타격 구간 종료 + 연계 지연 대신 교체 1타의 5번 프레임 진행도에서 연결한다. `KatanaWeaponVisual.Update`에서 예약 중 진행도를 제한하고, `LateUpdate`에서 정확한 5번 프레임의 Sword·Saya 자세를 평가한다. 해당 자세에서 마지막 칼날 검사를 확정한 뒤 `KatanaCombatCoordinator.TryStartFirstAttackFollowup`으로 다음 행동 ID의 2타를 시작한다.
- 이 전환에는 기존 0.08초 자세 보간을 적용하지 않는다. 2타 시작 자세가 1타 5번 프레임과 같으므로 진행도 0부터 바로 이어진다. 2타→3타·충전·반격·대상 돌진 규칙은 유지한다.
- `Player@KatanaSlash_2`의 Loop Time을 해제했다. 기존 Loop Time 때문에 종료 진행도 1에서 우상단 시작 자세로 다시 돌아가는 현상이 있었으며, 이제 종료·회복 중 기본 자세를 유지한다. 생성기도 다시 실행할 때 반복 재생을 해제한다.
- Unity 컴파일 성공. `NewAnimationTest` Play에서 기존 공격 API로 1타와 추가 클릭을 입력했다. 초반 입력 수락, 1타 약 0.322초에서 2타 시작, 양쪽 전환 위치 `(0.6803731, 0.136127159, 0.8646107)` 일치를 확인했다. 실제 Play 카메라 캡처에서 우상단 시작·우하단 준비·좌상단 베기·기본 자세 종료를 직접 확인했고, 종료 이후 DrawnWaiting에서도 기본 자세가 유지됐다.
- 기록과 실제 화면은 `Temp/KatanaComboReview/after.txt`, `final.txt` 및 PNG에 저장했다. 캡처 세션에는 이동을 런타임에서만 잠시 비활성화했다. 씬·프리팹·Controller는 저장하지 않았고 Play를 종료했다. 컴파일 오류 및 최종 Console 오류는 0개였다. 물리 마우스 입력·적 적중 피해·빌드는 미확인이다.

#### 연결 및 협업

- 연결된 기능: 카타나 전투 V2. 기존 Player의 Animation 창에서 해당 클립을 선택해 확인한다.
- 공유하는 코드 및 상태: 원본 애니메이션·Player 프리팹·씬·전투 스크립트는 수정하지 않는다.
- 중복 또는 충돌 사항: KatanaV2_Responsive.controller는 작업 전에 사용자가 수정한 상태이며 그대로 보존한다. 후속 요청으로 게임의 1타 선택은 KatanaWeaponVisual의 1타 AnimationClip 슬롯에 연결했다. 연결 방법과 검증은 [1인칭 근접 교전](1인칭_근접_교전.md)의 Inspector 교체 항목을 따른다.
- 승인 필요 사항 및 결과: 사용자가 첫·끝 프레임을 원하는 모습으로 수정한 뒤 기존 Iaido 중간 동작을 이어 달라고 명확히 요청했다.
- 현재 부모 KatanaRig는 위치 (0, 0.09, 0), 회전 (0, 0, 0), Scale (0.65, 0.65, 0.65)로 이미 원래 상태다. 별도의 부모 역회전 보정은 적용하지 않는다. 기존 Sword·Saya Transform Scale (0.72, 0.72, 0.72)을 유지하며 Scale 커브를 추가하지 않는다.

#### 시작·끝 자세와 연결

| 대상 | 시작·끝 Position | 시작·끝 Euler Rotation |
| --- | --- | --- |
| Saya | (-0.345346719, -0.3841864, 0.574509442) | (5.345, -77.704, 140.604) |
| Sword | (-0.351235539, -0.388525039, 0.5708481) | (365.345, -77.704, 140.604) |

- 0프레임과 10프레임의 사용자 값은 수정하지 않는다. 시작과 끝은 영상을 바탕으로 새로 창작하지 않고 현재 클립에서 직접 읽는다.
- 0~2프레임(0~0.033333초)은 사용자 시작 자세에서 원본 동작으로 연결한다.
- 2~8프레임(0.033333~0.133333초)은 원본의 같은 시각 위치·회전 및 중간 키·속도를 복원한다. 다른 초기 자세를 기준으로 원본 회전 변화량만 옮기는 방식은 사용하지 않는다.
- 8~10프레임(0.133333~0.166667초)은 원본 동작에서 사용자 끝 자세로 연결한다.
- 연결 시점의 탄젠트는 원본 Hermite 곡선의 정확한 미분값을 사용한다. 원본 중간 구간의 가속·감속을 유지하며, 맨 처음·끝 탄젠트는 0으로 정착한다.
- Rotation은 기존처럼 Euler 커브로 유지한다. Sword X의 원본 중간 각도에는 동등한 360도 오프셋을 적용해 사용자 시작·끝의 365.345와 연결할 때 불필요한 한 바퀴 회전을 막는다.
- 길이·프레임률·이벤트·Scale과 다른 경로의 커브는 유지한다. 추가 시간을 삽입하지 않는다.

#### 검증

- Builder 메모리 컴파일·실행 성공. 별도 테스트 코드는 작성하지 않았다.
- 2~8프레임 구간의 1001개 시각에서 실제 위치와 Quaternion으로 환산한 실제 회전을 원본과 비교했다. 최대 위치 오차는 Sword 약 0.000000179m, Saya 0m이며 최대 회전 오차는 Sword 약 0.0000426도, Saya 0도다.
- 시작·끝의 위치·Euler 값은 작업 전과 일치한다. 수정 전과 수정 후 첫·끝 프레임의 렌더 픽셀도 각각 동일했다.
- 원본·사용자 수정 전·복원본을 같은 Scale의 기존 Player 리그에서 각 21프레임으로 Outline 렌더링했고 실제 이미지를 확인했다. 중간 원본과 복원본의 윤곽선 자세가 일치함을 확인했다.
- 작업 전 파일 해시와 비교하여 대상 클립·해당 Editor 수정기·관련 명세 이외의 기존 파일 보존을 확인한다. 사용자 씬은 저장하지 않는다.
- 미확인: 게임 입력·적 피해 판정·빌드. Animator Controller나 전투 로직은 변경하지 않는다.
- 이번 수정 전 대상 클립 백업과 비교 프레임은 Temp/KatanaSlashEndpointRevision에 보관한다. Apply 재실행 시 현재 시작·끝 값은 보존하지만 중간 수동 편집은 원본으로 다시 복원된다.
