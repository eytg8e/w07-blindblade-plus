### 감각 표현

- 기능 설명: 공통 사건은 웨이브를, 걸음 요청은 발자국까지 독립적으로 표시하고 인지 마스크에 사건을 전달한다. 실제 순간 조명은 제거했다.
- 동작 조건 및 처리 흐름: FootstepEmitter가 지면 위치·법선·방향의 SensoryEvent와 별도 좌우 인수를 Game.SensoryManager.EmitFootstep에 전달한다. 일반 Emit 요청은 발자국을 생성하지 않는다. 매니저는 매니저의 거리 설정로 선형 감쇠하고 각 프리팹의 재생 API를 호출한다.
- 구현 상태: TASK_0018 표시 설정 매니저 통합, C# 컴파일 및 직렬화 내부 참조 확인 완료. 실제 PlayMode 검증 미확인.

#### 연결 및 협업

- 연결된 기능: Game은 기존 Managers.Resource로 매니저 프리팹을 풀링 없이 생성한다. 효과는 기존 Poolable/Resource를 재사용한다.
- 공유하는 코드 및 상태: 발자국·웨이브의 가시성은 같은 걸음 위치를 기준으로 계산하며 수명은 각각 독립이다. 세션 관측자는 SetObserver로 전달하고 씬 언로드·세션 종료 시 참조와 활성 효과를 정리한다.
- 중복 또는 충돌 사항: 사건 종류·발생원 참조·강도·거리 곡선과 충돌·소리 설정을 제거했다. 사용자가 삭제한 SensorySource는 복원하지 않고 남아 있던 시연 참조와 씬의 누락 컴포넌트를 제거했다.
- 승인 필요 사항 및 결과: 사용자가 현재 걸음 기능에 불필요한 타입 구분과 수치 축소를 요청했다.

#### 인스펙터 및 검증

- 추가 연결 없음. SensoryManager에는 Full Visibility Distance, Maximum Distance, Footstep Prefab, Wave Prefab을 설정한다. 같은 프리팹의 SensoryPerceptionMask에서 인지 반경·수명·경계를 설정한다.
- 발자국 수명·페이드와 웨이브 수명·시작 및 종료 반경은 각각의 프리팹 컴포넌트에서 조절한다.
- 배치 오프셋은 별도 수치 대신 각 효과 프리팹 루트의 로컬 위치를 표면 회전에 맞춰 적용한다. 발자국 Y 0.01m를 유지했다.
- C# 컴파일 성공 및 씬·프리팹 내부 fileID 확인 완료. 실제 재생·거리 변화·풀 재사용은 미확인이다.

- 공개 API: Emit(SensoryEvent)는 웨이브만 재생하고 EmitFootstep(SensoryEvent, bool isLeft)는 발자국을 추가한다. 공통 데이터에는 발자국 좌우 정보가 없으며 거리 판정과 생성 처리는 공유한다.
- TASK_0022: 두 요청이 거리 판정을 통과하면 효과 생성 전에 PerceptionRequested(SensoryEvent)를 발행한다. 매니저 프리팹의 SensoryPerceptionMask가 Position을 받아 주변 윤곽선의 일시 인지 영역을 등록하며 실제 Light 밝기와 독립이다. 기존 생성 성공 반환값과 효과 수명은 유지한다.
- 연결 위치: Assets/Scripts/GameManagers/SensoryManager.cs와 Assets/Scripts/Rendering/SensoryPerceptionMask.cs, Assets/Resources/Prefabs/GameManagers/SensoryManager.prefab. 플레이어 중심은 기존 SetObserver(Transform) 입력을 사용하며 FootstepTestDriver 외의 게임 세션 연결은 아직 없다.

- SensoryPresentationSettings 스크립트와 Footstep 설정 에셋은 제거했다. 거리와 효과 참조는 SensoryManager 리소스 프리팹으로 옮겼으며 기존 값과 효과 GUID를 유지했다.
- TASK_0023: 사용자가 불필요한 실제 순간 조명 제거를 요청하여 매니저의 조명 참조·풀 준비·생성을 제거하고 SensoryLightEffect.cs·SensoryLight.prefab 및 meta를 삭제했다. Unity 재컴파일 완료(오류 없음), 삭제 GUID의 Assets 잔여 참조 없음. 제거 후 Play 재검증은 수행하지 않았다.

#### MainMap 이동 감각

- MainMapSession이 Start에서 SensoryPerceptionMask.SetFootstepOnly(true)를 설정한다. 상시 관측자 반경은 0이며 적·환경의 PerceptionRequested는 윤곽선 마스크를 갱신하지 않는다.
- PlayerController.FootstepEmitted 착지 이벤트가 RevealFootstep(step.WorldPosition)를 호출하여 기존 Sound Radius / Sound Lifetime / Edge Fade로 주변 윤곽을 표시하고 페이드한다. 별도 발자국·웨이브는 생성하지 않는다.
- 정지 시 새 착지 영역이 생성되지 않고 마지막 영역의 수명 종료 후 시각 정보가 사라진다. 시점 회전과 벽에 막힌 입력은 표시를 갱신하지 않는다.
- 실제 수평 이동을 MainMapSession.Update에서 감지한다. Movement Grace 기본 0.12초는 걸음 사이의 짧은 쉼에도 소리 제한을 유지한다. 대시는 실제 이동 중 소리만 제한하며 착지 영역을 생성하지 않는다.
- 이동 중 Managers.Sound.SetFootstepOnlyOwner(player)는 플레이어 소유 SoundId.Footstep만 허용한다. 진입 시 기존 효과음을 정지하고 BGM 인스턴스를 음소거한다. 정지 후 제한을 해제하고 BGM을 복구한다. FMOD를 직접 호출하거나 Unity AudioSource로 재생하는 소리는 이 제한의 대상이 아니다.
- MainMapSession 비활성화 시 감각 정책과 소리 제한을 복구한다. 다른 씬의 기존 감각 표현은 유지한다. 사용자가 제안을 승인하여 기존 A 자동 구현으로 진행했다.
- 연결 코드: Assets/Scripts/Maps/MainMapSession.cs, Assets/Scripts/Rendering/SensoryPerceptionMask.cs, Assets/Scripts/Managers/SoundManager.cs. 외부 사운드는 Managers.Sound.Play/PlayAttached를 사용하고 owner를 지정해야 한다.
- MainMap에서는 SetEffectsVisible(false)로 기존 발자국·웨이브 생성을 억제하고 활성 효과를 숨긴다. PerceptionRequested 사건 전달 자체는 유지하되 마스크는 착지 전용 정책으로 다른 사건을 무시한다.
- 검증: Unity 재컴파일 오류 없음. Play의 임시 CLI 호출로 착지 표시 영역 1개, 외부 효과음 차단, 정지 후 재생 허용, 만료된 영역 0개, 외부 감각 사건 표시 0개, 별도 발자국·웨이브 0개를 확인했다. BGM 음량 0→1 복구와 세션 재활성화 시 상시 반경 0을 확인했다. 수명 검증은 사건 시간을 만료시키는 방식으로 수행했으며 실제 화면·청취에 의한 체감 검증은 미확인이다. 테스트 파일은 추가하지 않았다.

#### 발걸음 파동 제거 및 흰색 발자국 (2026-10-10)

- EmitFootstep은 좌우 발자국만 생성한다. EmitEffects의 wave 생성 조건에 !showFootstep을 추가했다. 인지 사건 전달과 기존 발소리·수명·거리 감쇠는 유지한다.
- 일반 Emit 요청의 웨이브는 유지한다. 발걸음 때문에 생기는 원형 확산 효과만 제거한다.
- Assets/Resources/Footstep/Footstep.prefab의 좌우 SpriteRenderer Color를 모두 RGB(1,1,1)로 설정했다. 페이드 시 알파만 변한다.
- 검증: Unity 컴파일 오류 없음. StraightCorridor Play에서 좌·우 EmitFootstep 성공, 파동 증가 0개, 활성 좌우 발자국 색 RGBA(1,1,1,1)를 확인했다. 실제 이동 중 화면 체감은 미확인이다.

#### 플레이어 이동 중 적 발자국 숨김 (2026-10-10)

- MainMapSession.Update의 실제 수평 이동 판정과 Movement Grace(0.12초)를 사용해 SensoryManager.SetEffectsVisible(Show Enemy Footsteps && !moving)을 적용한다. 착지 이벤트에서도 즉시 숨긴다.
- 이동 중 기존 발자국의 알파는 0이며 새 발자국을 생성하지 않는다. 정지 후 유예 시간이 지나면 수명이 남은 발자국과 이후 새 발자국을 표시한다. Show Enemy Footsteps가 꺼진 씬은 계속 숨긴다.
- 플레이어 착지의 주변 윤곽선 표시는 별도 RevealFootstep 경로를 그대로 사용한다. 검의 상시 윤곽선은 유지한다.
- 검증: Unity 재컴파일 오류 없음. StraightCorridor Play 임시 호출에서 정지 생성 성공·알파 1, 실제 위치 이동 후 알파 0·생성 차단, 정지 유예 만료 후 알파 1 복구를 확인했다. 검증 후 Play를 종료했다.
