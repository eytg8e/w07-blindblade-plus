### 감각 표현

- 기능 설명: 여러 오브젝트의 걸음·충돌·소리 사건을 공통 관측 거리 정책으로 발자국·웨이브·순간 빛에 표현한다.
- 동작 조건 및 처리 흐름: 발생원이 Game.Emitter에 SensoryEvent를 전달하면 거리와 종류를 판정하고 기존 Managers.Resource/Pool로 선택한 효과를 각각 생성한다. 남은 효과의 가시성은 사건 발생 위치와 현재 관측자 거리로 갱신하며 각 효과는 자신의 수명으로 반환된다.
- 구현 상태: TASK_0009~0012 구현 및 C# 컴파일 완료, TASK_0013 씬·프리팹 연결 완료. 실제 PlayMode 검증은 미확인.

#### 연결 및 협업

- 연결된 기능: Game이 보유하는 SensoryEmitter를 여러 발생원이 공유한다. Managers의 기존 리소스·풀·사운드 API와 초기화 계약은 변경하지 않았다.
- 공유하는 코드 및 상태: 사건 강도는 0~1이며 최대 거리 이상이면 생성하지 않는다. 발자국 프리팹은 걸음에서만 사용한다. 효과별 배치 오프셋과 무관하게 같은 사건 위치를 거리 기준으로 사용한다.
- 중복 또는 충돌 사항: 캐릭터의 OnFootstepEmitted는 접촉 알림만 제공하고 시연 구독자는 횟수만 센다. 양쪽 충돌 발생원이 활성 상태로 같은 충돌을 담당하면 Rigidbody 보유 쪽을 우선하고 같은 조건에서는 인스턴스 ID가 작은 쪽만 전달한다. 발생원별 최소 충격량과 재전달 간격을 적용한다.
- 승인 필요 사항 및 결과: 사용자가 Game 보유·Managers 재사용 구조와 나머지 Task 전체 구현을 요청했다. 새 싱글턴·정적 사건 버스·테스트 코드는 추가하지 않았다.

#### 인스펙터 연결 및 사용

- FootstepTest 씬의 추가 사용자 연결은 없음. Game과 같은 객체의 SensoryEmitter, 두 관측자, 세 설정, 독립 효과 프리팹, 충돌 Rigidbody/Collider, 소리 클립을 연결했다.
- 다른 게임 씬은 Game에 자신 또는 자식의 SensoryEmitter를 연결하고 Emitter에 관측자와 사건별 설정 3개를 지정한다. 캐릭터에는 FootstepEmitter와 지면 레이어를, 충돌·소리 오브젝트에는 필요에 따라 SensorySource를 연결한다.
- 씬 전환 후 지속 중인 Game의 Emitter에 새 관측자를 SetObserver로 연결하고 Initialize를 호출한다. 관측자 씬 언로드 및 Emitter 비활성화는 EndSession으로 기존 효과와 참조를 정리한다. ClearObserver는 남은 효과를 숨기고 자체 수명은 유지한다.
- 기존 소리를 재생하는 지점에서는 ReportSound를 한 번 호출한다. PlaySound는 연결된 클립을 Managers.Sound로 먼저 재생한 후 사건을 전달한다. 기존 사운드 API는 위치 없는 재생이며 공간 음향을 추가하지 않았다.
- 표시 설정에서 프리팹을 비워 효과별로 끌 수 있다. 거리·반경·지면 오프셋은 미터, 수명·페이드는 초, 충격량은 뉴턴·초 기준이다. 빛이 주변을 비추려면 조명 반응 재질과 추가 조명 지원이 필요하며 시연 바닥은 URP Lit을 사용한다.

#### 검증

- Unity 참조 기반 전체 런타임 C# 컴파일 성공. 일반 C# 컴파일러의 SerializeField 미할당 경고만 발생했다.
- 씬·세 프리팹·세 설정의 내부 fileID와 필수 연결을 확인했고 기존 씬·발자국·웨이브의 GUID를 보존했다.
- Unity CLI는 다른 프로젝트만 연결되고 대상 에디터 컴퓨터 제어가 시간 초과로 실패하여 실제 플레이 검증은 미확인이다.
- 가까움·감쇠·경계·범위 밖의 세 사건, 관측자 교체·파괴, 세션 재시작, 좌우·지면 배치, 충돌 중복 방지, 독립 수명·풀 재사용 및 거리 밖 실제 소리 재생은 실행 확인이 남아 있다.
