### 감각 표현

- 기능 설명: 현재 캐릭터의 걸음 위치에 발자국·웨이브·빛을 독립적으로 표시한다.
- 동작 조건 및 처리 흐름: FootstepEmitter가 지면 위치·법선·방향·좌우 선택을 Game.SensoryManager에 전달한다. 매니저는 단일 표시 설정의 거리로 선형 감쇠하고 각 프리팹의 재생 API를 호출한다.
- 구현 상태: TASK_0016 설정 축소, C# 컴파일 및 직렬화 내부 참조 확인 완료. 실제 PlayMode 검증 미확인.

#### 연결 및 협업

- 연결된 기능: Game은 기존 Managers.Resource로 매니저 프리팹을 풀링 없이 생성한다. 효과는 기존 Poolable/Resource를 재사용한다.
- 공유하는 코드 및 상태: 세 효과의 가시성은 같은 걸음 위치를 기준으로 계산하며 수명은 각각 독립이다. 세션 관측자는 SetObserver로 전달하고 씬 언로드·세션 종료 시 참조와 활성 효과를 정리한다.
- 중복 또는 충돌 사항: 사건 종류·발생원 참조·강도·거리 곡선과 충돌·소리 설정을 제거했다. 사용자가 삭제한 SensorySource는 복원하지 않고 남아 있던 시연 참조와 씬의 누락 컴포넌트를 제거했다.
- 승인 필요 사항 및 결과: 사용자가 현재 걸음 기능에 불필요한 타입 구분과 수치 축소를 요청했다.

#### 인스펙터 및 검증

- 추가 연결 없음. 표시 설정에는 Full Visibility Distance, Maximum Distance, Footstep Prefab, Wave Prefab, Light Prefab만 남는다.
- 발자국 수명·페이드, 웨이브 수명·시작 및 종료 반경, 빛 수명은 각각의 프리팹 컴포넌트에서 조절한다. 빛 색상·강도·범위는 기존 Light 컴포넌트에서 조절한다.
- 배치 오프셋은 별도 수치 대신 각 효과 프리팹 루트의 로컬 위치를 표면 회전에 맞춰 적용한다. 발자국 Y 0.01m와 빛 Y 0.4m를 유지했다.
- 빛은 전체 수명 동안 선형 페이드하며 별도 페이드 시간 설정을 제거했다.
- C# 컴파일 성공 및 씬·프리팹 내부 fileID 확인 완료. 실제 재생·거리 변화·풀 재사용은 미확인이다.
