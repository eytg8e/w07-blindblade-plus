### 플레이어 걸음 보행

- 기능 설명: 「261009 전투 시스템 발전기획」의 변경 사항 2번에 따라 연속 보행을 한 걸음 이동과 짧은 쉼으로 바꾸어 조심스러운 이동을 표현한다.
- 동작 조건 및 처리 흐름: PlayerMotor가 이동 입력을 받으면 대기 없이 걸음을 시작한다. SmoothStep 위치 곡선의 변화량으로 0.28초간 가속·감속 이동하고 착지 이벤트 후 0.08초간 수평 이동을 멈춘다. 입력 유지 시 반복한다.
- 구현 상태: 구현 완료. MainMap 설정 및 Unity 컴파일·Play 검증 통과.

#### 연결 및 협업

- 연결된 기능: 일반·가드·충전 완료 보행, 기존 PlayerFootstepEvent 및 MainMapSession 발소리.
- 공유하는 코드 및 상태: FootstepEmitted의 PlayerFootstepEvent 계약을 유지한다. Quiet는 충전 완료 보행이며 소음 0.2, 일반·가드 보행은 Normal이며 소음 0.6이다. 착지 때 이벤트를 발행하므로 이벤트 소비자는 별도 거리 타이머를 사용하지 않는다.
- 중복 또는 충돌 사항: 적 FootstepEmitter·AI, 감각 표현, Input Actions, PlayerController 및 발도 대시 알고리즘은 변경하지 않는다. MainMap 플레이어에 별도 FootstepEmitter를 추가하지 않는다. 카메라 흔들림·발자국/파동 추가는 이번 범위에서 제외한다.
- 승인 필요 사항 및 결과: 사용자가 제안한 걸음 이동 → 착지 → 쉼 구조를 진행하도록 승인했다. 기존 A 자동 구현 모드와 development/combat 자동 커밋 지침을 따른다.

#### 조정 변수와 동작

- Step Move Duration 0.28초, Step Pause Duration 0.08초. 걷는 동안의 평균 속도는 기존 Walk Speed이며 한 걸음 거리는 평균 속도 × (이동 시간 + 쉼 시간) × 입력 세기다.
- MainMap Walk Speed 1.388889m/s이면 한 걸음 약 0.5m다. Guard Walk Speed 0.6944445m/s이면 0.25m, Charging Walk Speed 0.5555556m/s이면 0.2m다.
- 이동 중 시점과 방향을 조절할 수 있다. 대각선 입력은 정규화하며 아날로그 입력 세기는 걸음 시작 시 보폭에 반영한다.
- 입력 해제 시 Deceleration으로 짧게 감속한 뒤 착지한다. 쉼 시간은 입력을 놓았다는 이유로 초기화하지 않는다. 잠금·사망·대시 시작은 보행을 즉시 초기화한다. 중력은 쉼에도 적용한다.
- 벽에 막혀 0.02m 이하로 움직였거나 접지하지 않은 걸음은 발소리를 생략한다. 부분 이동 후 정지한 걸음도 실제 이동량이 충분하면 한 번 발행한다.
- 기존 Acceleration 필드는 직렬화 및 공개 프로퍼티 호환용으로 남기고 Inspector에서 숨긴다. 걸음 가속·감속 곡선은 Step Move Duration으로 조정하며 입력 해제 감속은 Deceleration을 사용한다. 이전 Normal/Quiet Step Distance 필드는 걸음 타이밍으로 대체한다.
- 다른 기존 씬은 저장된 이동 속도를 유지한다. 메인맵만 제안한 평균 속도로 조정한다.

#### 검증

- Unity 컴파일 오류 없음. Play에서 임시 CLI 호출로 검증했으며 별도 테스트 스크립트는 작성하지 않았다.
- 100·50·60fps 시간 간격에서 두 걸음 약 1m, 착지 이벤트 2회, 정지 후 속도 0을 확인했다. 일반 약 0.5m, 가드 약 0.25m, 충전 약 0.2m 보폭 및 0.08초 쉼 동안 수평 이동 0을 확인했다.
- 입력 해제 감속과 정지 후 드리프트 0, 완전히 벽에 막힌 동안 이동 및 착지 이벤트 0, 기존 대시 0.5m 종료와 보행 이벤트 0을 확인했다.
- 걸음 경계의 부동소수점 잔여 시간으로 접지를 잃고 착지 이벤트가 누락되는 문제를 수정했다. 체감 리듬과 실제 청취는 사용자의 플레이로 최종 조정한다.
