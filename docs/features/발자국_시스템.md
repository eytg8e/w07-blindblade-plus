### 발자국 시스템

- 기능 설명: 캐릭터 한 개의 이동 거리와 지면 접촉으로 좌우 걸음 사건을 전달하고 독립 발자국 객체가 표시·페이드한다.
- 동작 조건 및 처리 흐름: FootstepEmitter는 이동 구간을 보간해 좌우 발 위치의 지면을 검사하고 Game.SensoryManager.EmitFootstep에 공통 사건과 별도 좌우 인수를 전달한다. 순간이동은 누적 거리를 초기화한다. 거리 판단과 프리팹 생성은 공통 SensoryManager가 맡는다.
- 구현 상태: 적 추적과 공통 감각 표현 연결 및 Unity 컴파일 완료. EnemyChaseDemo의 실제 추적 이동에서 지면 접촉 13회와 기존 적 이벤트 중계 13회를 확인했다. 추가 이동 처리 직후 발자국·파동·빛 각 2개 생성과 총 활성 효과 6개를 확인했다. 정지 후 효과 수명에 따른 정리를 확인했다. 기존 FootstepTest 시연의 전체 항목은 이번 작업에서 재검증하지 않았다.

#### 연결 및 협업

- 연결된 기능: [감각 표현](감각_표현.md)의 Game.SensoryManager와 기존 Managers.Resource/Pool을 사용한다. FootstepEmitter에는 관측자·프리팹·거리 정책을 두지 않는다.
- 공유하는 코드 및 상태: OnFootstepEmitted는 Action<Transform, Vector3> 인스턴스 이벤트이며 최대 거리 밖에서도 캐릭터와 접촉 위치를 전달한다. 시연 구독자는 효과를 추가 생성하지 않는다.
- 중복 또는 충돌 사항: 기존 스크립트·프리팹 GUID와 FootstepObject 이름을 유지했다. 사용자가 삭제한 테스트와 씬 생성 코드는 복원하지 않았다.
- 승인 필요 사항 및 결과: 공통 거리 정책과 독립 효과 구조를 사용자 요청으로 연결했다.
- 적 연결 작업: 사용자 요청으로 EnemyFootsteps가 FootstepEmitter의 접촉 이벤트를 중계하도록 연결한다. 생성은 공통 Emitter 한 곳에서 담당하고 기존 적 거리 계산은 활성 Emitter가 있을 때 실행하지 않는다. 적 EnemyFootsteps가 Start에서 기존 Game의 매니저를 사용하고 관측자가 비어 있을 때만 EnemySensor.Target을 설정한다. 팀원 FootstepEmitter·SensoryManager 생성 로직은 변경하지 않는다.

#### 인스펙터 및 검증

- 캐릭터에는 Step Distance, Foot Offset, Teleport Distance, 지면 레이어 및 Ray Height/Depth를 설정한다. 발자국 프리팹의 좌우 렌더러와 기본 수명은 유지하며 재생은 프리팹의 수명을 사용한다.
- EnemyChaseDemo의 적 3개에 FootstepEmitter를 연결했다. Step Distance는 0.7m, Ground Layers는 예제 지형의 Default 레이어다. 다른 지형을 사용하면 해당 레이어로 변경한다. Hierarchy에 Game 매니저가 없으면 추가한다. 별도 플레이어 바인딩 없이 적 코드에서 관측자를 연결하며 다른 기능이 이미 설정한 관측자는 유지한다.
- EnemyFootsteps는 활성 FootstepEmitter의 접촉 이벤트를 전달한다. 이때 자체 거리 계산과 NotifyFootstep은 중복 알림을 발생시키지 않는다. 공통 Emitter가 없거나 비활성화되면 기존 이벤트 전용 동작이 남지만 시각 효과는 생성하지 않는다.
- 루트 +Y는 지면 법선, +Z는 진행 방향이며 스프라이트 자식의 로컬 X 회전은 90도이다.
- 테스트 씬의 연결은 완료했고 C# 컴파일·직렬화 참조는 확인했다. 좌우 교대·지면 정렬과 실제 재생은 미확인이다.

- 연결 방식 수정: 사용자 요청으로 SensoryObserverBinding 의존성을 제거했다. 팀원 코드 수정 없이 적 코드와 Hierarchy 연결만 변경했다. 이번 변경은 실행 검증하지 않았다.

- 적 발걸음 사운드 연결: EnemyFootsteps가 접촉 알림마다 EnemySoundSettings 공통 에셋의 Footstep을 기존 Managers.Sound.Play에 한 번 전달한다. 개별 적의 소리 설정은 제거하며 공통 기본값은 Footstep이고 None이면 소리를 요청하지 않는다. 이벤트 수신자가 같은 소리를 중복 재생하지 않도록 한 경로만 사용한다. 팀원 FootstepEmitter와 사운드 매니저 코드는 변경하지 않았으며 이번 실제 재생은 미확인이다.

- Inspector 정리: 적 EnemyFootsteps의 On Footstep 연결 목록을 제거하고 Footstep C# 이벤트만 유지한다. 공통 접촉 구독, 감각 효과 생성과 공통 소리 호출은 유지하며 팀원 코드는 수정하지 않는다. 이번 실행은 미확인이다.
