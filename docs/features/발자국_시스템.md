### 발자국 시스템

- 기능 설명: 단일 캐릭터의 이동 거리마다 좌우 발자국을 지면에 배치하고 관측 거리와 수명에 따라 표시를 제어한다.
- 동작 조건 및 처리 흐름: FootstepEmitter가 이동 구간을 보간하여 좌우 지면을 검사하고 캐릭터와 접촉 위치 이벤트를 발행한다. FootstepObject는 발자국 알파와 수명만 관리하고 종료 시 기존 풀로 반환한다. 순간이동은 누적 거리를 초기화한다.
- 구현 상태: 파동 참조와 호출을 제거하고 발자국 프리팹에서 링 자식을 분리했다. 게임 코드 컴파일과 씬·프리팹 내부 참조 확인 완료. 이번 변경의 실제 PlayMode 실행은 미확인.

#### 연결 및 협업

- 연결된 기능: 기존 Managers.Pool 및 Managers.Resource로 생성·반환한다. 캐릭터마다 자신의 Emitter를 보유하고 Game에는 발자국 참조와 중계 이벤트가 없다.
- 공유하는 코드 및 상태: OnFootstepEmitted는 Action<Transform, Vector3> 인스턴스 이벤트이며 해당 캐릭터와 지면 접촉 위치를 전달한다. 최대 관측 거리 밖에서도 접촉 이벤트는 발행된다. 구독과 해제는 동일한 Emitter에서 OnEnable/OnDisable에 맞춘다.
- 중복 또는 충돌 사항: FootstepObject와 FootstepEmitter는 파동 컴포넌트를 참조하지 않는다. 사용자가 삭제한 기존 자동 테스트 및 씬 생성 코드는 복원하지 않았다.
- 승인 필요 사항 및 결과: 사용자 요청에 따라 발자국과 파동의 코드, 프리팹 및 수명을 분리했다.

#### 인스펙터 연결

1. 캐릭터의 Emitter에 Footstep Prefab, Observer 및 지면 Collider 레이어를 연결한다.
2. 발자국 프리팹 루트에는 FootstepObject와 Poolable을 두고 Left Renderer와 Right Renderer에 서로 다른 좌우 스프라이트 렌더러를 연결한다. 파동 참조는 필요 없다.
3. Step Distance, Foot Offset, Ray Height/Depth, Surface Offset은 미터 기준이고 Lifetime/Fade Duration은 초 기준이다. Maximum Distance는 Visible Distance보다 크게 설정한다.
4. 루트의 +Y는 지면 법선, +Z는 이동 방향이며 스프라이트 자식은 로컬 X 회전 90도로 배치한다.
5. 테스트 씬의 시연 컴포넌트에는 Character, Observer, Emitter 및 선택적 Wave Prefab을 연결했다. 추가 사용자 연결은 없다.

#### 검증

- 파동 연결 없이 FootstepObject가 구성되는 것을 코드 및 프리팹에서 확인했다.
- 발자국·파동·시연 코드의 Unity 참조 기반 C# 컴파일에 성공했다. 씬과 두 프리팹의 내부 fileID를 확인했다.
- 기존 TASK_0007의 10개 자동 테스트 통과는 분리 이전의 검증 기록이며 이번 변경의 실행 결과는 아니다. 현재 자동 테스트 파일은 삭제되어 있다.
- 독립 파동의 사용법은 [파동 연출 명세](파동_연출.md)를 따른다.
