# 엔딩 연출

- 기능 설명: EndingScene에서 SO 독백을 순차 표시한 뒤 2초 동안 검게 페이드하고 메뉴 IntroScene으로 돌아간다.
- 동작 조건 및 처리 흐름: 씬 시작 시 직접 연결한 MonologueUI를 초기화한다. 각 대사는 Space·Enter·숫자패드 Enter·좌클릭의 새 입력이 올 때까지 유지한다. 자동 진행은 없다. 마지막 대사에서 진행 입력을 받으면 UI를 숨기고 전체 화면 FadeToBlack의 CanvasGroup 알파를 0에서 1로 변경한다. 검은 화면을 한 프레임 유지한 뒤 IntroScene을 비동기 로드한다.
- 구현 상태: 게임 플레이 세션이나 플레이어가 없는 엔딩에서도 기존 독백 UI 프리팹을 사용한다. 시간 진행에는 unscaledDeltaTime을 사용하고 메뉴 복귀 시 timeScale을 1로 복구한다. 실제 플레이 검증은 사용자 지침에 따라 미확인이다.

## 연결 및 협업

- 연결된 기능: 기존 MonologueUI와 MonologueData를 재사용한다. 게임 세션을 요구하는 MonologueController는 변경하지 않는다.
- 공유하는 코드 및 상태: 독백의 마지막 삼각형 표시 계약을 유지한다. IntroScene에는 엔딩 복귀용 페이드 오버레이를 연결한다.
- 중복 또는 충돌 사항: EndingScene에 복사되어 있던 IntroMenu·VolumeControlUI를 해당 씬에서 비활성화하고 메뉴 제목·버튼·음량 패널을 숨긴다.
- 승인 필요 사항 및 결과: 사용자가 엔딩 시스템 구성 및 IntroScene 복귀를 요청했다. EndingScene은 빌드 목록 끝에 추가하여 기존 씬 순서를 유지한다.

## 편집 방법

- EndingMonologue.asset의 Lines에서 최종 문구를 입력한다. 현재 두 문구는 편집용 예제다.
- EndingSequence의 EndingSceneController에서 Fade Duration, Menu Scene Name을 변경한다. 대사는 입력으로만 진행한다.
- 씬의 기존 미저장 변경을 보존하므로 새 연결은 사용자가 씬 저장 후 다른 씬에서 로드해야 한다.

## 검증 및 제한

- Play Mode, 플레이 테스트, 화면 캡처는 수행하지 않는다.
- 연결 전 기존 TutorialGuide.cs의 병합 충돌이 컴파일을 막고 있었다. DisplayKeys의 장치별 표시와 null 참조 방어를 모두 유지해 충돌 표시를 제거했다.

- 최종 편집 상태 확인: 독백 두 개, MonologueUI 및 Fade 참조, Fade Duration=2, 목적지 IntroScene, EndingScene 빌드 등록을 확인했다. Unity 컴파일 완료·오류 없음. 기존 미저장 씬 변경을 보존했으며 EndingScene은 저장하지 않았다.

## 2026-10-13 수동 대사 진행

- 사용자 요청으로 4초 자동 진행과 관련 Inspector 옵션을 제거했다. Space·Enter·숫자패드 Enter·좌클릭의 새 입력마다 한 대사만 진행한다.
- 연결된 EndingMonologue.asset에 두 대사가 모두 존재하고 MonologueUI 본문 연결이 정상임을 편집 상태에서 확인했다. 사용자 수정 문구는 변경하지 않았다.
- 첫 대사에서 입력하면 두 번째 대사를 표시하며, 두 번째 대사에서 다시 입력해야 2초 페이드와 IntroScene 복귀를 시작한다.
- 기존 자동 진행 때문에 입력 없이도 두 번째 대사와 종료로 넘어갈 수 있었다. 실제 화면에서 한 대사만 보인 원인은 플레이 테스트 없이 확정하지 않았으며 자동 진행 제거 후 사용자가 확인한다.
- Play Mode·플레이 테스트·캡처는 수행하지 않는다.


## 2026-10-13 IntroScene 복귀 페이드인

- Assets/Scripts/UI/IntroFadeInController.cs의 RequestFadeIn으로 다음 메뉴 진입의 페이드인을 요청한다. EndingSceneController는 메뉴 씬 로드 직전에 요청한다.
- IntroScene의 IntroReturnFade에 전용 Overlay Canvas와 CanvasGroup을 연결했다. Awake에서 검은 화면을 설정하고 알파를 unscaledDeltaTime으로 2초 동안 1에서 0으로 줄인다.
- 페이드 중 메뉴 CanvasGroup의 Interactable을 끄고, 완료 후 원래 상태를 복구한다.
- IntroScene을 처음 직접 실행할 때는 요청이 없으므로 페이드 없이 메뉴를 표시한다. 새 실행 세션 시작 시 정적 요청을 초기화한다.
- IntroScene에 미저장 변경이 없음을 확인하고 저장했다. 원래 활성 EndingScene으로 복귀했다. Unity 컴파일 오류 없음. Play Mode·플레이 테스트·캡처는 미실행이다.
